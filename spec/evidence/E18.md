# E18 Puzzle prerequisites
## Behaviour
Progression that needs several objects is expressed by trigger tests combining state of multiple objects: `TrigTest_MultiGaoActive@0x4656d0` (all of up to four listed objects, plus the first slot defaulting to Jack, have object flag bit 0 set; `param+0x64` inverts), `TrigTest_ALL_GAO@0x465810` (equals the count of "needed" objects held by the Univers counter `+0x4e10` when the parameter `+0x54` is 1..4), `TrigTest_Active`, `TrigTest_CapaBit/CapaBitOr` (capability bits), `TrigTest_Levier` (player holds a lever, E10), `TrigTest_PositionGrilleEnflam` (fire), and the door system itself (E09/E11: every pillar operated). Level scripts AND these into the action that opens a gate.
## Code
`TrigTest_MultiGaoActive`, `TrigTest_ALL_GAO`, `TrigTest_Levier@0x469940`, `TrigTest_PositionGrilleEnflam@0x46a360`, `InteractiveDoor_loop@0x876330`.
## Numbers
4 object slots; `TrigTest_ALL_GAO` accepts parameter values 1..4 as "need exactly this count" and anything else as "any non-zero count" [C].
## Data
Trigger graphs in level banks.
## Rust
None beyond the building blocks (doors in `companions`, fire in `environment`).
## Gaps
Per-level prerequisite graphs are data.
