# A13 Bait distraction (raptor view; one species)
Main doc: `spec/evidence/X02.md`. The engine class `PNJ_Raptor_*` serves species 0xe (raptor), 0x10 (Jack-level V-Rex), 0x16 (compies); this is how the **raptor** (0xe) does it.

## Behaviour (what the game does)
The raptor has no bait-specific code. Food is any perceived actor with life 0 (flag 0x400) or class 0x21; rule 6 of target selection prefers the nearest such corpse unless the raptor is in VALA/MORD/GRAB/COODBOOL or has a wait timer; it then runs ATTENTE/FIGHT -> DEVORE and eats (gives up after 3.0 s without food). Jack outranks food only through rule 3, which runs before it, so a raptor that already sees Jack ignores bait.

## Code
`exec_update_best_interest@0x863360` rule 6/9, `ETAT_DEVORE@0x86a9f0`, `fn@0x47e180`.

## Numbers
corpse must be within 50 m of Jack (2500 sq) [C]; DEVORE approach distances 10/12/7 m [L meaning].

## Data
Which level objects register as class 0x21: level data.

## Rust
`select_target` rule order test.

## Gaps
Rule order between 3 (Jack) and 6 (corpse) needs the lost assignments of rule 2 confirmed.

## V-Rex view (added with X04)
Same chain, rex specifics (`vrex_jack::select_target`): any dead creature beacon (life fraction 0) or level corpse is bait; the rex takes the nearest unclaimed reachable one **before** it considers a calm Jack in its narrow cone, and DEVORE keeps it busy (meat bite 4 per second, so a corpse with N meat points holds it N/4 s). Bait loses to shooting: once Jack has done > 10 damage (flag 0x21) rule 3 sends the rex after him again, and noise alone can pull it back after 1.5 s without a target. While in GRAB (holding someone) rules 3 and 6 are off. Details and numbers: `A12.md`, `G17.md`, `X04.md`. A thrown/placed bait item has no code in `PNJ_Raptor_*`; bait must be a corpse-class actor or object (class 0x21 or life fraction 0).
