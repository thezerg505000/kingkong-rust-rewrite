# H03 Damage recovery
## Behaviour
Jack does **not** regenerate. When the wound timer elapses the status goes 1 -> 2 (recovering; hit logic identical to healthy, life ratio 0.3, injury overlay stays). Only Ann cures: `H_ETAT_ann_heal` sets status 0 (5.0 s of healing, 2.0 s when the patient is Jack and alive). The older "regen 8 s" belongs to the AI-companion branch (`H_ETAT_IA_stunned`, N10.md) and was wrongly applied to Jack.
## Code
- `H_TRACK_joueur@0x5816f0` (~line 795): `status==1.0 && Time_Elapsed(this[0xb93], this[0xcfa])` -> status 2.0. `this[0xcfa]` = wound length copied from `this[0xb8f]` by the receiver; when status==0 it is reset to 10.0 (line ~800).
- `H_ETAT_ann_heal@0x5d0380` (lines ~870-890): heal timer `this[0xc18]` += dt; `local_60 = 5.0`, `2.0` if patient slot 1 and Jack not dead; at the end `G+0x1bb4+4*patient = 0`, `G+0x1c00+4*patient = 3`, and for Jack `Jack[0x2e3c] (=0xb8f hurt timer) = 0`. Also `H_ETAT_ann_climb@0x5dcc40` line 1275 writes status 0 (Ann reaching a ladder/climb end for slot), `fn@0x5ee140` is a setter used by script (`TrigExec_EtatHumain@0x78b3c0` sets any status).
- Dead Jack can be revived by Ann while the death state has not yet restarted (ann_heal tests `G+0x1bb8==3.0`; `H_ETAT_IA_mort` returns to state 5 when status becomes 0).
