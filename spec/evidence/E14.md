# E14 Breakable supply crates (weapon crates)
## Behaviour
The weapon crate is the `SA_*` object (`SA_init@0x56c5b0`, `SA_ETAT_Fall@0x56f530`, `SA_ETAT_WaitAccroche@0x56dab0`, `SA_ETAT_Loop@0x56ccc0`, `SA_echange@0x56d630`, `SA_add_data@0x56d560`): a crate with one weapon type (`this[0xb6]`, 1..4 Colt/Tommy/Shotgun/Sniper) and an ammo count (`this[0xb7]`) that arrives on a parachute, lands, and then offers its content. It is "opened" by interaction rather than broken: within 2 m of the crate (`Obj_DistSq < 4.0`) the prompt id 9 is shown; interacting runs the weapon exchange `SA_echange`.
`SA_init` spawns the crate only if up to 4 script tests (`this+8..` pairs of test/args) pass; the crate position/orientation is saved in a Univers table (`G+0x1250+12*id`) so it reappears at the same place after a checkpoint; if the player already holds as much as the crate offers (`crate_ammo - (clip + reserve) < 1`) the crate is removed at spawn (when `this[0xb8] == 0`) [C].
While falling: spin damping `1 - clamp(dt)` toward 0 with `dt * spin * 5.0` rotation, parachute pieces hidden on landing (ground contact flag 0x40 triggers dust FX and parachute removal), after landing a small random wobble on the lid (`0.03 * sin(...)`), decaying `-2.0/s`. 4 visual variants (one per weapon: meshes 2-3 Colt, 4-5 Tommy, 6-7 Sniper, 8-9 Shotgun) plus a mesh 10 "more than a clip" indicator when the crate ammo exceeds the weapon's clip (`G+0x475c..`) [C].
## Code
`SA_echange`: if the taker's weapon differs from the crate's, the taker's old weapon (with clip+reserve) goes into the crate (crate weapon/ammo replaced, or emptied when the old ammo is 0) and the taker's cells for it are zeroed; the taker receives the crate ammo: `room = clip_size - clip`; if `give < room` add to clip else clip = full and the rest to reserve; finally clip -1 / reserve +1 (reload bookkeeping); taker is Jack (slot 1) -> anim 0x66, flag `+0x41cc` [C]. `SA_ETAT_Loop` sets `G+0x456c = weapon` and `G+0x4570 = taker` when the pickup animation hands over (`H_TRACK_Reflex` completes it).
Ammo boxes (`Munition`) are the other supply object (I07.md).
