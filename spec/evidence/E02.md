# E02 Fire ignition
## Behaviour
Three ignition paths exist, all verified in code. (1) Ground fire: a level trigger action `TrigExec_Burn` (parameters: object, burn time) starts a grid fire at the nearest unburnt flammable cell (own cell, else the first of its 8 neighbours); the test `TrigTest_PositionGrilleEnflam` reports whether the cell at an object is burning. (2) Physics props (`ode_*`) ignite when they take a paf whose flag word has bit 0x200000 and the prop has the "can burn" slot set. (3) Lamps/torches (`it_*`, `Xenon_Activate_Light_*`) light when a fire zone contains their point, a nearby grid cell burns, or a level flag forces them. A lit spear (the 6/7/8 held items near a fire line, `fn@0x4d5b60`; or Ann's `KAnn_exec_action_javelin_set_fire` in Kong levels) is the player-facing source; the link spear -> level object is level script data.
## Code
See `E01.md` (SGF, TrigExec_Burn, ode_check_trigger, Fire_PointInFireZone). Extra: `Javelin_launch@0x879190` (lit spear, `this[0x3e]`, stops in grass when a flight sample cell is material 5 with an unburnt material-8 cell below), `Javelin_waittaken@0x87d160` (spear that sits on a burning cell: `local_44=1` and it is removed from play), `KAnn_exec_action_javelin_set_fire@0x5ffb50`, `PHIL_SFX_FireOnLance@0x607da0`.
## Numbers
Fire pafs: flag 0x200000 [C]; `TrigExec_Burn` start search = own cell then 8 neighbours [C]; lit-spear zone radius 0.5 [C]; Ann lights the spear at frame 65 (`0x41`) of anim 0x5f [C].
## Data
Trigger parameters per level (object, burn time `param+0x18`).

## Gaps
Which weapon/spear state raises the paf bit 0x200000 against props (the bit is produced on the sender side; `Javelin_*` burning spears add +10 damage per `S` docs) is not traced. Level scripts that call `TrigExec_Burn` are data.
