# N03 Call interaction
## Behaviour
Jack has no "call" button for companions in the code that was found. What exists is a prompt system: actors publish interaction proposals (`H_INTERACTION_add_data@0x5d84e0`: type `this+0x19ec`, enabled by `this+0x19f0`), the player activates one (object flag 0x8000), `H_INTERACTION_check@0x5d85c0` (called from `H_TRACK_Reflex`) clears the flag and latches `this+0x19f0 = 1`, and the companion then runs its response state: the weapon-exchange "psss" sequence (`H_ETAT_IA_psss`, see I09.md). The AI side proposes jobs with `H_INTERACTION_propose@0x5d8640` (order types 1 assist, 2 heal, 3 use/pickup/film/door, 6 carry), each proposal weighted by distance. Aiming: when Jack raises a weapon with a companion within 2 m and within +-16 deg of the aim direction (`dot > 0.96`), the aim request is cancelled (`H_exec_read_joy`, slots 2..6 at `G+0x1c98`) [C].
## Code
`H_INTERACTION_propose` order switch: 1 -> `H_exec_propose_help` (AI only; offers to assist Jack when Jack holds a weapon of kinds 1,2,3,4,6,7,8, target within 10 m, 1.0/2.0/3.0 weight depending on whether the companion has a usable weapon), 2 -> `H_exec_propose_heal` (Ann), 3 -> `ramasse` (kinds 1,4) / `film` (3) / `porte` (5) / `use`, 6 -> `H_exec_propose_carry` [C]. Proposal tick rates: door 2.0 s (`this+0x3b58`), heal 2.0 s (`this+0x3000`), carry 1.0 s (`this+0x1a34`) [C].
