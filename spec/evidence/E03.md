# E03 Fire transfer
## Behaviour
Fire moves between connected things in three code-confirmed ways: across the ground grid cell by cell (one cell per spread interval, 8-neighbourhood, flammable material only), along a waypoint network as a travelling front (`SFX_NET_Fire`, speed = length/traverse time, flame every 1.4 m), and between touching/linked physics props (burning prop with flame intensity >= 1.5 pafs every touching or linked prop with fire flag 0x200000; intensity grows 0.01 per frame from 0.5, so spread starts ~100 frames after ignition; the prop burns 10 s).
## Code
`SGF_Propage@0x6827c0`, `SFX_NET_Fire_ETAT_Init@0x4d6890`/`_Burn@0x4d6c90`/`_Write@0x4d6db0`, `fn@0x4d5e50` (front advance), `ode_exec_gestion_feu@0x6a3740`; details in `E01.md`.
## Numbers
See `E01.md` table: ring 200, spacing 1.4, 1.5 spread intensity, 10.0 s burn, 0.01/frame [C].
## Data
Network ids/lengths (`SFX_NET_Fire` +0x19c, +0x1a8), burn time (`+0x184`), traverse time (`+0x178`): level instance data, not decoded.
## Rust
`environment::GridFire`, `OdeBurn`. Tests `grid_fire_spreads_one_cell_per_interval_and_burns_out`, `ode_fire_timeline`. The network front is not ported (rendering-heavy).
## Gaps
`SFX_NET_Fire` extinguish/restart cadence beyond `+0x184` and the `Write` (re-seed) state use are not mapped.
