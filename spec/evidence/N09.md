# N09 Retreat behavior
## Behaviour
There is no flee-to-fixed-point routine. Two mechanisms make a companion move away: (1) the shoot state is left when the target is closer than the kind's safe distance (T-Rex 10 m, raptor 6 m, small 4 m, ...) and a 3.0 s retry cooldown starts, after which `H_exec_select_action` and the follow state pull it back to its formation slot; (2) the cover states pick a hiding network node (`H_exec_ch_hide_0D@0x591890`, cover nodes carry a reservation counter at `(node+0x18->+8)+8`, incremented when taken, decremented when released, flag 0x40 = limited capacity) and run to it; at 1.0 s in the state the companion sets the "available" flag 0x800.
## Code
- `H_ETAT_IA_tir` exit (N04.md) [C].
- `H_ETAT_IA_hide@0x5ab150` (0x25b): cover search every >0.2 s (`this+0x349c`), keeps the chosen node `this+0x137c`, re-picks after 3.0 s with no usable node (`this+0x348c > 3.0`), asks `H_exec_ch_hide_0D`; leaves when `this+0xab0` (threat gone) or `this+0xab4`, or after `this+0x41d0` seconds of being stuck (`this+0x2f1c`, then hurry flag `this+0x19cc = 1`); arrival radius 3 m (`dist² < 9.0`) [C].
- `fn@0x547390@0x547390`: true when any of slots 2,3,5,6 has status exactly 0.15 (a hidden/special status) [C].
## Numbers
cover re-pick 3.0 s, stuck limit `this+0x41d0` (set by script, sub-code 0x19), arrival 3 m; retry cooldown 3.0 s [C].
## Rust
`companions::shoot_should_exit` (retreat trigger), `SHOOT_RETRY_COOLDOWN_S`.
## Gaps
