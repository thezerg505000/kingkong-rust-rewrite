# A06 Chase (raptor view; one species)
Main doc: `spec/evidence/X02.md`. The engine class `PNJ_Raptor_*` serves species 0xe (raptor), 0x10 (Jack-level V-Rex), 0x16 (compies); this is how the **raptor** (0xe) does it.

## Behaviour (what the game does)
`ETAT_FIGHT` (2) chases while the target was confirmed within the last **1.5 s**, else drops to SEARCH. Chase uses path mode 0 (direct/territory net) toward the target; speed gait index `+0x2118` with acceleration `10*dt` (m/s^2) up and a `6*dt` blend down, x1.5 for 3 s after `+0x218c` is active; a wounded raptor (hp < 30 %) uses another gait. Wait timer mode (`+0x1aa4 != 0`) circles the target at 5.0 m (path mode 3) before the next run. New target -> HESITE first.

## Code
`ETAT_FIGHT@0x84f380`, `ETAT_SEARCH@0x852680`, `ETAT_HESITE@0x864c30`, `exec_way_find_dest_pos@0x83ff10`, `exec_select_action@0x83a950`.
