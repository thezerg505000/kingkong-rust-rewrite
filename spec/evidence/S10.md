# S10 Limited spear supplies
## Behaviour (what the game does)
A world pickup (`ib` item box, type 0/1/2 -> weapon 6/7/8) is single use: taking it clears the mailbox flag and `ib_waitdestroy` removes the box. Thrown spears that stay in the world are also limited by the 32-object cap and the 15 m / 3 s despawn rule (S08).

## Code
`ib_wait`@0x6ef900 (sets `G+0x456c/0x4570/0x4574=0/0x4578=0/0x457c=1` on pickup), `ib_waitdestroy`@0x6f0590 (destroys when `G+0x4570 == 0`), `ib_init`@0x6f0320 (type 0/1 hotspot id 7, else 8), `Javelin_exec_addinworld`@0x87f110 [C].
Note: for type 2 the box first writes `G+0x457c = 3` and then overwrites it with 1 in the same block, so the stack count that reaches Jack is 1 [C].

## Rust
`spears::WORLD_CAP`, `eviction_index`.

## Gaps
Per-box finite counts (like ammo boxes) are not present in `ib_*`; supplies are level-placed objects. Pickup range of boxes is the generic interaction zone (not isolated).
