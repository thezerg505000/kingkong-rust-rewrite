# W04 Vegetation interaction
## Behaviour
Brush that burns = ground material 8 (E01). Brush that obstructs movement = nav tags / solid objects placed by the level (E16, E08); `KInteractive_Shrub@0x6a80a0` only binds a model key (`0x4d00161a`) and has no state of its own, `Interactive_Bambou` is the bamboo pickup (E08), `btode_*` are breakable trees (E13). Concealment: no vegetation-specific code was found; creature perception uses line-of-sight raycasts and cone/distance tests (species `check_vision`), so tall grass hides only through level geometry or by being a LOS blocker [L]. Tall grass is also a physical hazard in one respect: the V-Rex ignores grid fire (species 0x10 excluded) but raptors/scorpions/megapedes do not.
