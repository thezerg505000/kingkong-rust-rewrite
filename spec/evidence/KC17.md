# KC17 Multiple opponents
Main document: `spec/evidence/KC01.md`.

## Behaviour (what the game does)
Kong does not have an explicit crowd mode; three mechanisms handle several enemies:
1. **Opponent list**: `k_exec_select_opponent@0x8c4d30` (called by `k_reflex` every frame) lists all type-8 message sources within 100 units (dist^2 < 10000)
   into `Kong+0xfec[]` (with positions `Kong+0xef8`, directions `Kong+0xe04`, kinds `Kong+0x1040`). The target `Kong+0xcf4` is the listed object whose direction
   has the **largest dot with the stick** (best-aligned; the decompiler swaps the two local labels, checked in the disassembly); a target of class b99f64 with
   flag 0x80 wins immediately. The previous target is kept (sticky) if it is still listed and closer than 12 (144 sq).
2. **Aim assist** at every punch start (`fn@0x8848e0` -> `fn@0x882990`): re-aims the attack direction within a 45 degree cone to an enemy within 8.0 (search 100); score
   = angle score minus distance/10 (plus distance/10 for flag 1).
3. **Hit list per swing**: one swing hits each victim once (`Kong+0xd34[]`, cleared at every phase start), so a sweep can hit several enemies. Riders (up to 5,
   `Kong+0x10cc`) are not hit by the sweep (`Kong+0x1ac8` excluded) and **two or more riders disable the dodge button**.
The V-Rex pairs Kong with a target choice of its own (`KT_exec_fight_actor_select`, B02).
