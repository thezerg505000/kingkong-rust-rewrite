# J08 Hip-level movement
Weapon carried lowered while moving without aim. Evidence is animation selection in `H_exec_select_action@0x587bd0`: with the run flag
set Jack plays run animations keyed by current weapon id (`G+0x3344+4*p`): 1/5/9 -> 0x69, 2 -> 0x6c, 3 -> 0x6b ... when not running and
not aiming the base walk animation is 0x33 (weapon 1: 0x32, 3: 0x34, 4: 0x35, 5/9/10: 0x37, 6-8: 0x36); aiming uses 0x3a/0x3c/0x3b/2/0x3d
[C ids, L meaning]. No numbers beyond animation ids. The flag +0xbf8 ("arme basse", set by `H_ETAT_IA_paf@0x594400` after a hit) blocks
select_action (returns 0) until the idle animation 0x29/0x2a/0x2b ends [C].
Status stays INFERRED_IMPLEMENTATION: no gameplay numbers, the look is in the animation data.
