# N12 Scripted waiting (pointer: N01.md, N14.md)
## Behaviour
Characters wait because a level script put them in a cinematic wait state, not because of companion code that watches Jack. The trigger actions send a message to the actor: `TrigCINE_Wait@0x765480` (code 0x186a1, also clears flag 0x2000), `TrigCINE_WaitDefault@0x7654d0` (0x186a5), `TrigCINE_ResetWaitDefault@0x765510` (0x186a6, for up to 5 actors), `TrigCINE_ForceEtat@0x766250` (0x186a7). The script proceeds with `TrigCINE_WaitDisponibility@0x7664e0` which passes when every listed actor has flag 0x800 (reached the follow state for 1.0 s) [C]; `TrigCINES_WaitCapa@0x765d40` passes when a flag mask on the actor is set; `TrigCINES_WaitGoal@0x765860` waits for goal nodes. `H_CINE_Wait@0x585cb0`, `H_CINE_WaitDefault@0x583bc0` are the states they put the human into. `NET_Follower_ETAT_wait` is the equivalent for walkers (radius or flag armed, then delay).
## Code / Numbers
See N01.md and N14.md. Queue capacity 20 messages per human (`H_exec_ch_msg`: "Trop de messages cines humains") [C].
