# J14 Damage movement feedback
## Behaviour
Being hit takes control from the movement code: the hit state (`H_ETAT_IA_paf`, state id 700) replaces the normal select_action locomotion, clears the aim flags, plays the hit reaction
and sends a screen-effect message with code 2. After the reaction a lowered-weapon flag (+0xbf8) keeps `H_exec_select_action` from running (it returns 0) until the idle anim 0x29/0x2a/0x2b ends. When
Jack's wound state (G+0x1bb4+4p) is 3 (dead) the velocity is zeroed (`H_TRACK_Post@0x5c8370`) and the death state sends code 4. There is no persistent "limping" speed penalty in
`H_exec_select_action` tied to the wound state; the only global slowdown flag is +0x1a30 (target 1.5), set while an effect object at +0x1180 is in state 6 (nature unknown, offset belongs to the "Flamme2" fire/gas group in the model, L).

- `fn@0x6e5060@0x6e5060` (named `Msg_SendJackScreenFx`): builds a message (id 0x38d1b717, type 0x16, argument = code) to the effects layer; codes seen: 2 (hit), 4 (wound state 3 / death, `H_TRACK_joueur` line 597, `H_ETAT_IA_mort` 246/507/518, `H_TRACK_Reflex`), 5 (`H_TRACK_Reflex` while +0xf4e).
- `H_TRACK_Reflex@0x58de70` lines 1020-1045: wound state G+0x1bb8 == 1.0 -> loops an animation/sound handle (+0xb51 = 8 or 9) and requests camera rumble `fn@0x693590(DAT_00b99304, 0.5)`; state 3 -> code 4.
- `CM_Cam@0x45b1b0` 0x45d526: wound state 3 zeroes camera +0xa8 (pitch accumulator).
