# H09 Instant-kill hazards
## Behaviour
Instant kills are: (1) paf flag 0x200 (V-Rex grab 0x4a10); (2) dwelling in a deadly volume (Jack object flag 0x40 queried through `fn@0x42b770(obj,0x40)`): 1.0 s of continuous contact (accumulator `this[0xd1e]`, advanced only while `fn@0x689f80(pos)` is true) sets status 3 (`H_TRACK_Reflex`, line ~1117-1130); companions need 2.0 s; (3) `H_TRACK_joueur` (line ~810): when the same flag is set (or `this[0xbf4]`, a mode flag) and the two timers `this[0x347c]` > 2.5 or `this[0x3478]` > 1.0 -> status 3; between (0 < `0x3478` or `0x347c` > 1.5) Jack is pushed out by a self-sent hit (`Msg_BuildHit`, flags 0x42, direction x3, `this[0x3398]=1` if `this[0x2e3c]` > 0.5). Falls kill through this path when the landing/fall volume carries the flag [L]; no fall-height number was found.
Also the script setter `TrigExec_EtatHumain@0x78b3c0` writes any status.
