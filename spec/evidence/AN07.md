# AN07 Combat restrictions (some Kong combat/object interactions require putting Ann down)
Main doc: `AN01.md`.

## Behaviour
The engine does not forbid the actions; it **puts Ann down automatically**. Three Kong states clear the carry flags and send the hand-category message 9 to Ann's held object, which makes `KAnn_ETAT_grabbed_KK` leave to `follow_network` (category 8 or 9 -> release, AN02): `k_ETAT_grab@0x8dae10` (grabbing an enemy/object, line 1258: `if (+0x318 != 0) { if (+4) {+4 = 0; +0xc = -1} ; fn@0x7dcd40(+0x2b4, 9) }`), `k_ETAT_finished@0x8b5c80` (finisher, line 363: `+4 = 0; +0xc = -1; +8 = 0; fn@0x7dcd40(+0x2b4, 9)`), and `k_ETAT_jump@0x8c6690` (line 808: when `+8 != 0 && +4 == 0` the held-object message is re-queried and the hand index reset). `k_ETAT_grab_ANN` itself clears `+0x12c4`, `+0x370` and the fury carry flag `+0x1e14` when it ends. So: **grabbing an enemy, performing a finisher** drop Ann where Kong stands; **jumping** resets the hand slot; while Ann is merely carried Kong keeps walking and fighting with the free hand (melee `k_exec_melee_hit@0x88e0c0` has no carry test [C by absence]).
Also `k_exec_propose_grab@0x8b5970` offers enemies (Scolo, raptor, bat classes) to Kong only if fury is off and the Kong state `+0x5c` is not 1000, 0x160, 0x385 (and for class `0x3e9` never) and `Kong+0x1af4 == 0` [C]; the grab target must be `fn@0x606480(Kong, target) > 2` away [C].

## Code
`k_ETAT_grab@0x8dae10`, `k_ETAT_finished@0x8b5c80`, `k_ETAT_jump@0x8c6690`, `k_ETAT_cine@0x8931a0` l.287-297 (cutscene state re-binds the Ann query), `k_ETAT_colonne_exec@0x8eb890` l.1300 (column climb: needs `Kong+0x318 == 0` to start the hand-over), `k_exec_propose_grab`, `k_exec_propose_ride@0x8d5aa0` (riding a bat/raptor: needs `Kong.state != 0x3e9`, distance < 7 m for class `b99f44`; no carry test).

## Rust
Not separately ported; `kong::ann::AnnState` documents the release target. A future Kong state machine must call "release Ann" on grab/finish.

## Gaps
Fury (`Kong_IsFuryOn`) behaviour while carrying: `k_ETAT_grab_ANN` writes `Kong+0x1e10 = 0.5` and clears flag 0x2000 on Ann when fury was on at pick-up [C], meaning not decoded.
