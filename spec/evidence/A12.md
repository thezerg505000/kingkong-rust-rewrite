# A12 Corpse feeding (V-Rex view; raptor view in `A13.md` / `X02.md`)
Main doc: `X04.md`.

## Behaviour (what the game does)
Any perceived actor whose published life fraction is 0, or whose class is 0x21, is flagged `0x400` (carcass) by `fn@0x47e180`. Dead humans are removed from the list instead (unless they are in the jaws), so a dead Jack is never "food". Level corpse objects (`KCadavre_Wait@0x880df0`, class from `+4`, interest 150, life fraction 0) and the dead bodies of creatures (their beacon keeps publishing hp/hp_max = 0 from `PNJ_Raptor_reflex`) both become carcasses.
Rule 6 of the target chain picks the **nearest reachable carcass that is not already claimed** (`0x2000000`), unless the rex is in VALA/MORD/GRAB/COODBOOL; if Jack has an attach parent the carcass must be within 50 m of him. It sits above "living prey in the narrow cone" and below Jack-shot-me / hurt-me, so a calm Jack in plain view loses to bait, a shooting Jack does not.
In DEVORE the rex walks to the carcass's eat bone, stops 6-8 m from it (0.75*8 .. 8), plays the eat clip (0xf, 0x49) and every 1.0 s sends the corpse a paf with flags 0x800 and damage 4: the corpse's meat counter (`KCadavre +0x38`, skipped when -1) falls 4 per second until the object is destroyed. If the previous state had lasted > 0.5 s the rex roars on starting to eat. While eating the wide vision cone is skipped (it sees humans in all directions given line of sight), Jack inside sqrt(6) m triggers `hard_grab`, and an attached Jack beyond 50 m makes it drop the corpse. A rex that grabbed a class 0x14 carcass (anim 0x49, frame > 30) holds it with the grab hand-shake. [C]
