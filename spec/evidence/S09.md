# S09 Spear degradation
## Behaviour (what the game does)
Durability is a counter. Type 0 (weapon 6, developed spear) has a budget of 6, type 1 (weapon 7, bone spear) 4; every embed costs 2, so 3 and 2 embeds. The counter is carried with the spear (`G+0x1d78` while in hand,
`javelin+0x218` in the world). A spear at or above the budget can no longer embed: it hits for half damage and bounces. When it is destroyed it leaves broken pieces.

## Code
- `Javelin_init`@0x8783a0: `this[0x8c] = 6` (type 0) / `4` (type 1); type 2 is left unset [C].
- `Javelin_launch`: `if (wear < max) wear += 2` on a stick [C]; `Javelin_waitdestroy`@0x87f600: if `wear >= max`, `this[0x21c]==0`, `this[0x100]!=0` (broken-piece template) and type 0/1: spawn the template at the spear, send it message 0x7d3 (gravity -20, tumble), sound 0xe (type 0) / 0xf (type 1) [C].
- `Jack_SpearWearStage`@0x68a3c0: base 6 (weapon 6) / 4 (weapon 7); stage 0 if wear < base, 1 if wear < base+3, else 2; selects the dropped model (`Jack_DropHeldThrowable`) and the throw template (`H_ETAT_IA_lance`: `G+0x1d78 >= base` swaps template) [C].

## Rust
`SpearKind::{max_wear, embeds_available}`, `Spear::{can_embed, is_spent, wear_stage}`; tests `durability_is_three_embeds_for_developed_two_for_bone`, `wear_stage_matches_original_thresholds`.

## Gaps
Type 2 default `this[0x8c]` is a model variable (not in the exported ova set); assumed 0 [L]. Whether a spent spear is still re-pickable by design: the code allows it (no check on wear in `Javelin_waittaken`).
