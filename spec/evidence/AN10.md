# AN10 Rescue objectives
Main doc: `AN01.md`.

## Behaviour
Rescues become objectives through the trigger layer, not through Ann's code: `TrigTest_KBigBat_IsGrabbingAnn` and `TrigTest_KBigBat_PlungeonAttack` are boolean tests that level scripts use as conditions ("bat has Ann", "bat is plunging"), `TrigExec_KAnn_Fear_Set` writes `Univers+0x8908` (Ann scared; read in `KAnn_TRACK_init` as `Ann+0x44`), `TrigExec_KAnn_On_Shoulder_Set` the carry mode, `TrigExec_KAnn_Check_Paf_on_Network` makes her check hits while following a network, `TrigExec_KAnn_Drop_Javelin` forces her to drop her javelin. Objective strings are in the text bank (`TextObjectifs`), not decoded here. `KAnn_exec_CHECK_msg@0x5fb130` accepts message type 5 (script kill/abduction end -> `mort`) and type 3/6 (script data) [C].
Failure: Ann death (AN04) raises `Univers+0x4dd4 = 30.0`; the game-over handler is outside `KAnn_*` [L].

## Code / Numbers
Globals written: `+0x8908`, `+0x890c`, `+0x891c`, `+0x8920`, `+0x8998`, `+0x899c` [C].

## Rust
None (script glue). The port's trigger layer should expose these six globals.

## Gaps
The objective text/ordering per level and the game-over timer consumer.
