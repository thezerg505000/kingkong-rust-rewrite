# X05 Megapede (`PNJ_Scolo`, size types 0, 3, 4)
Status RESEARCHED. X06 (smaller millipedes) shares the class: `X06.md`.

## Behaviour
`PNJ_Scolo_*` (37 functions `@0x806e90-0x83121c`) is the centipede/"scolopendre" class used in both Jack and Kong levels. Type (`Scolo+0x0`) picks the size class in `PNJ_Scolo_exec_settings@0x826150`: types 0 and 3 are the large ones (X05), types 1 and 2 the smaller ones (X06), type 4 an invulnerable set piece, type 5 is left to instance data (its settings switch is skipped; `+0x14 != 0` forces life 1). It lies in `Sol` (ground/cover) or `Pit` (hole) until prey comes near (`Apparition` pops it out of its hole), attacks (`Attaque`, lunge and bite via `test_bite`), can jump (`Jump`), snaps/constricts (`Snap`), eats corpses (`Devore`), and has Kong-specific states `Grabbed_By_Kong`, `KKBite`, `KKRide`, `KKFinish`, `KK_I_Finish`, `Cine_*`. Kong can ride and finish it.
