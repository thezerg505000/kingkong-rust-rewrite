# I05 Spear pickup
## Behaviour (what the game does)
Two sources: item boxes (`ib`, type 0/1/2 -> weapon 6/7/8) and spears already thrown into the world (S08). Both write the same mailbox (`G+0x456c` id, `+0x4570` taker, `+0x4574` lit, `+0x4578` wear, `+0x457c` count, `+0x4580` extra) and `H_TRACK_Reflex` applies it.

## Code
`H_TRACK_Reflex`@0x58de70 (bytes for lines 541-655): id not 1..4 and not 0x15..0x1e: if id in {5,9,10} -> `Jack_DropHeldThrowable` then slot update (lever special-case); elif id == A: only weapon 8 refreshes its stack; else: drop held throwable, lever to C, `if B == 0: B := A`, `A := id`, `G+0x4520 := lit` for 6/7/8, `G+0x366c := count`, `G+0x1d78 := wear` (player) [C].
Pickup is refused by the world object when Jack already holds the same id, or when the spear is 7 and Jack holds 6 [C].
