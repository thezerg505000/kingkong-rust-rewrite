# P01 Story chapters
## Behaviour
The campaign is a fixed list of 42 map ids; each map is a "chapter" with a type (1 Jack, 2 Kong, 3 menu). Entering a map sets the chapter index and zeroes its stat record.
## Code
- uni_go@0x794ed0: on map change finds `G+8` in the campaign list (`G+0x5010+4i`, 42 entries), sets chapterIdx `G+0x2d94` (default 0x31), zeroes `G+0x2da0/4/8` and the 20-float stat record [C].
- ES_ExitMap@0x6f45d0: next map `this[0x920]`, entry id `this[0x921]`, fade `this[0x922]` [C].
- Level table: `code/ova/uni_init_all.txt` (82 entries; id, world key, flag, name index, type) [C].
