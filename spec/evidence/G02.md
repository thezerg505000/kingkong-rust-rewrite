# G02 Fire
## Behaviour (what the game does)
Pulling the trigger fires the held weapon (switch on `G+0x3344+4p`: 1 Colt, 2 Tommy, 3 Shotgun, 4 Sniper).
If the magazine is empty the game starts a reload instead (`H_exec_loading_weapon`). Colt, Tommy and Sniper
use one hitscan (`fn@0x540fd0`); the shotgun casts 25 rays itself (G11).

## Code
- `H_callback_tir` @0x5bbd10: gate for an AI companion (`*this==0`; AUDIT: `*this != 0` is the human player): if `this[0x60b]` (+0x182c, ova name v_cible_arme) is 0.0 the shot is cancelled (state reset, return 0); if `this[0x60c]` (+0x1830) < 0.95 it returns without firing (meaning [L]); sets `this[0x30a]=0.2`
  (0x3e4ccccd) in the `else` branch (`*this != 0`, the human player). Per weapon: decrement mag (`G+0x342c+0x48w+4p`, Colt shown at 0x3474), call hitscan, then
  `fn@0x53a370(w, fn@0x4150e0(shooter,target))` -> damage message `fn@0x6e3e70` [C].
- `fn@0x540fd0` @0x540fd0 (named `Weapon_Hitscan`): reads `w = G+0x3344+4p`, `range = float[G+0x465c+4w]` and casts
  `fn@0x42d400(self, origin, dir, range, -1, 0, 0, 0xb)` (named `Raycast_Object`); on a hit continues with `range -= distance`
  (`local_2c -= fn@0x405ad0`) for a second cast (pass-through) [C].
- Cooldown: there is no table. At the end of each case `H_callback_tir` stores a constant into Jack `+0x3bc8` and `+0x3bcc`
  (`local_46c[0xef2]=[0xef3]=c`): Colt 0.4 (0x3ecccccd), Tommy 0.2 (0x3e4ccccd), Shotgun 0.5 (0x3f000000), Sniper 0.4 (0x3ecccccd) [C values].
  Nothing in the decompiled code reads those two slots (the ova names there, `i_cur_expression`/`v_pos_lance`, are overlapped), so that they are
  the fire cooldown is [L]. Tommy's real auto-fire interval is explicit: shot n+1 fires when `n*0.1 <= elapsed` (`this[0x408]*0.1` vs `this[0x409]`) [C];
  for an AI companion the burst stops after 5 shots (`this[0x408] < 5`, `*this == 0`; the human instead fires while the trigger flag `this[0x2e3]` is held) [C].
- Weapon ids [C]: `GG_Exec_AppendWeaponName` 1 Colt, 2 TommyGun, 3 ShootGun, 4 SniperRiffle, 5 Grenade, 6 Javelin.
