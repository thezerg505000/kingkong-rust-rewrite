# J06 Crouching
## Behaviour (what the game does)
Crouch is a posture flag (+0xb60) on Jack. Depending on the control scheme (`fn@0x4401e0() == 2`) button 2 toggles it, otherwise it is
active while button 0xb is held; neither works while the grab timer (+0x2d3) is >= 0.5. While crouched the walking target speed is L*1.5, the
eye drops to 0.8 and the eye height eases with 5*dt. Wading deeper than 0.6 clears it. If Jack is in the crouched posture (+0x2da) and
the player releases crouch under a low ceiling, a probe forces it back on, so Jack cannot stand into geometry.
## Code
- `H_exec_read_joy@0x579f30` lines ~25-45 (toggle/hold), lines ~528-530 (`if depth >= 0.6: crouch = 0`), the ceiling probe (mid-function, after the aim-button block) (`fn@0x440620` (0,0,0.8) start offset,
  (0,0,1.0) direction, `fn@0x42d400(actor, &start, &dir, 0.8, -1, 2, 0, 1)`; hit -> crouch = 1) and the posture-change animations (`+0x2da != 0 && crouch == 0 -> anim 2`,
  `+0x2da == 0 && crouch -> anim 1`) near the end of the function; `+0x2b7 != 0` forces crouch; slow flag +0x1a30 clears it. `fn@0x68b380@0x68b380` sets +0xb60 = 1 (sets +0xb9c/+0xb90 = 0).
- `H_exec_select_action@0x587bd0`: speed branch (see J01); with crouch + moving, the animation set changes (local_50 0x19/0x23 for crouch idle).
- `CM_Cam@0x45b1b0` 0x45dba3-0x45dce0: eye height target.
