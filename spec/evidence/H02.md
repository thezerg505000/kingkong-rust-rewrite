# H02 Enemy damage (Jack's hit receiver; also the numbering fix for H01-H04)
## Behaviour (what the game does)
Jack has no HP. `H_exec_ch_Stimulus_Paf@0x5a3060` reads only the paf FLAGS (never the damage value). The status of slot 1 (`G+0x1bb8`) is **0 healthy, 1 wounded, 2 recovering, 3 dead** [C]. A hit on 0 or 2 wounds Jack and starts a wound timer plus a short invulnerability cooldown; a hit on 1 kills once the cooldown is over. Flag 0x200 kills at once. Both the wound length and the cooldown depend on how many times Jack has died since the last map change (G+0x4dc8): more deaths = shorter wounds (mercy mechanic).
The old `wounds.rs`/gameplay_spec labels (1 healthy, 2 wounded, 3 dead) were shifted by one; `G+0x4dc8` was mislabelled "difficulty". Both fixed in wave 3.
## Code
- `H_exec_ch_Stimulus_Paf@0x5a3060`, Jack branch (`*this != 0`). Gates (all must hold) [C]: `this[0xcdf]==0`, cheat `G+0xbf0 & 1 == 0` (invulnerable), `this[0xd2d]==0`, Ann/slot-1 status `G+0x1bb8 != 3`, state not 0x262 (carry) / 0x2c5 (carried); then `fn@0x43bd70(4,..)` pulls the next paf of queue 4; skipped if `this[0xedf]!=0` (also `this[0x4d4]!=0` clears the result), and a one-shot `this[0xce6]` swallows exactly one paf. A paf from the actor `fn@0x43fc70(0)` (self) is ignored unless `this[0x2a9]`.
- Fields copied from the paf: flags -> `this[0x321]`, direction `this[0x324..326]`, source `this[0x323]`, `this[0x327]`.
- Jack branch, only when cooldown `this[0x328]==0` [C]:
  - status==1 and cheat bit `G+0xbf0&0x200`==0 -> status 3.
  - else: stamp `this[0xb93]=Time_Now`, `Stats_CountWound@0x52f7b0`, status=1, then by flags and `G+0x4dc8` (0 / 1 / >=2):
- Whatever the cooldown: flag 0x200 -> status 3 (dead); else flag 0x100 and status!=3 -> status 1 (stamp + CountWound again). No flag ever raises 3 other than 0x200 and the cooldown-free second hit.
- After the status logic (Jack only): `this[0xcfb..0xd01]` set to 0.4, 0.1, 0.6, 0.5, 0.35, 0.25, 1.5 (0x3ecccccd, 0x3dcccccd, 0x3f19999a, 0x3f000000, 0x3eb33333, 0x3e800000, 0x3fc00000; camera-reaction blend weights [L]); camera reaction `fn@0x423e30(cam, 0x80000000)` normally, 0x8000000a when flag 2, 0x8000000b when flag 0x1000 (0x80000002 instead if `this[0x2d8]`, i.e. aiming); `fn@0xa69150(100,0x32)` = rumble (Jack only).
- Flag 0x40: knock-back direction vector recorded (0.1 s debounce `this[0x32c]`).
- `this[0xb8f]` hurt timer is published to `G+0x1ce4+4*slot` (and Time to `G+0x1d30+4*slot`); `GST_Global_go@0x693e90` decrements it per frame (the creatures' target selection reads "==0").
