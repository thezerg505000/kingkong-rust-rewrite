# P07 Weapon persistence (and I11 ammunition persistence)
## Behaviour
Weapons and ammo persist between consecutive chapters as ordinary Univers variables. When a chapter is started in replay mode (or from the chapter menu) a fixed per-chapter loadout is applied. Chapter 301 (Escape From natives) strips Jack's weapons on entry.
## Code
- fn@0x52ef90@0x52ef90 (Progression_ApplyChapterLoadout): clears current weapon (G+0x3344), 0x3390, 0x33dc and mags/reserves for 20 weapons (0x342c+w*0x48+4p, 0x39d4+w*0x48+4p); Jack weapon G+0x3348 from table 0x5340, Hayes G+0x3350 from 0x54d8; ammo split: magazine size {1:8,2:50,3:5,4:5}, if ammo>mag then mag=mag, reserve=ammo-mag, else mag=ammo [C].
- Called from ES_EnterMap@0x6f18d0 when this[1]==1 && G+0x5670!=0, and fn@0x4da570 [C].
- ES_EnterMap exception: G+0xc==1 && G+8==0x12d (301) clears Jack weapon slots 0x3348/0x3394/0x33e0 and mag/reserve of all 20 weapons [C].
