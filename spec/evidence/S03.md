# S03 Spear melee
## Behaviour (what the game does)
With a spear held, the melee button runs `H_ETAT_IA_frappe`@0x5a1020: animation 0x5f (spear stab; 0x69 when not a spear). A forward hit zone is tested; each hit sends one hit message with damage 1 (flag 0x40 if the held item burns, else 0x10), at most one per 0.4 s. The stab does not consume wear.

## Code
`H_ETAT_IA_frappe` weapon test `G+0x3344+4p in {6,7,8}` -> anim 0x5f; `H_exec_test_ZDE_FIGHT`@0x5915b0: `fn@0x42c550` zone query (type 6), skip self and model `DAT_00b992cc`, cooldown `fn@0x43c690(this+0x3038, 0.4)`, ray `fn@0x42d400(..., 5.0, ...)`, message `Msg_BuildHit(... 0x38d1b717, target, bone, 1, ...)` [C].

## Numbers
damage 1 [C], cooldown 0.4 s [C], reach 5.0 [C], flags 0x10/0x40 [C]. "Repel" effect is the creature's reaction to the message (species code).

## Rust
`spears::{MELEE_DAMAGE, MELEE_COOLDOWN, MELEE_REACH, melee_flag}`; test `melee_constants`.

## Gaps
The same function also serves the unarmed attack (anim 0x69); the damage scale vs creature health is unknown.
