# S16 Spear dropping
## Behaviour (what the game does)
Dropping places the held throwable on the ground in front of Jack as a pickup object and returns the stored weapon to the hand: slot0 := slot1, slot1 := 0, and if slot 2 holds the lever (10) it moves to slot 1. A lit item is dropped lit. Wear stage (0/1) chooses which model is dropped.
