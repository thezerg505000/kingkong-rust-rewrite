# KC14 Environmental weapon
Main documents: `spec/evidence/KC06.md` (grab), this file (wield).

## Behaviour (what the game does)
Grab objects (`KInteractive_Grab_Object` / `KIGO_*`, e.g. tree trunks) publish proposals with message kind bit 2 (`KIGO[0] == 0`: throwable)
or bit 4 (`KIGO[0] != 0`: wieldable). When Kong takes a kind-4 object, `k_ETAT_grab` sets `Kong+0x378 = 1` ("holding"), `Kong+0x18d4 = 1`, plays the
hold anim (0x96 + slot) and the main state becomes `k_ETAT_main_souche@0x8e2250` (the held-object variant of `k_ETAT_main`, same action id 0xfa).
Controls while holding: attack = swing (anim 0xc2 right, then 0xc4 left, alternating; from idle the side remembered in `Kong+0x18a8`),
special = overhead smash (anim 0xc6). A swing can be followed when its animation passes frame 0x23 (35) or at the cancel flag; the smash
only at its animation end (it then increments the object's use counter `Kong+0x344+slot*8`). Every swing blow does 10 (20 in fury), class 2, the
smash class 10 (2|8); `k_exec_zdf_zdc` sweeps while the window flag is up. The held-weapon state is left by the jump button (`Kong+0x7c` -> state b99f70)
or when the object is released/destroyed. A thrown object (kind 2) uses `KIGO_ETAT_projectile` and hits with class 2 / 0x22 and `KIGO+0x18` damage.
