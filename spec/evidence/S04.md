# S04 Spear aiming
## Behaviour (what the game does)
There is no separate aim posture for the spear: Jack throws toward the point 20 m in front of the camera (S05). The throw state (id 0x2c2) is entered from the weapon button when a non-firearm is held; animation 0x5c (spears) or 0x56.

## Code
`H_ETAT_IA_lance`@0x5ca1e0 aim point; `H_exec_read_joy`@0x579f30: `Jack_IsNonFirearmHeld` gates the button mapping [C]. Camera/aim assist: Jack var 0xb41.. holds an explicit aim point when set [C].

## Rust
`spears::aim_point`.

## Gaps
Aim-assist target selection, crosshair/hud, and the animation event frame are not isolated.
