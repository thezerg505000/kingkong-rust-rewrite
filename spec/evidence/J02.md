# J02 Backward movement
Same mechanism as forward: see `J01.md`. There is no back-specific speed, cap or animation branch in
`H_exec_select_action@0x587bd0`; backward is the stick pushed so that the camera-relative vector built by
`GG_Exec_Joy@0x695030` points opposite the camera forward (`move_direction`). Speed = same target table [C].
Gaps: the original may slow backward walking through the chosen animation set / root motion; no code for it was found. [L]
