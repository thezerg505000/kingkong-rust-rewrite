# I08 Weapon supply (Englehorn drops)
## Behaviour
The drop itself (Englehorn's plane, timing) is not in AI2C code: `Avion_NY@0x6c4790`, `OBJ_parachute@0x6c29c0`, `OBJ_FuseeDeDetresse@0x772eb0` (distress flare) are only GAO-key bindings; the plane flyover is level script / cinematic. What the code does implement is the crate that falls (`SA_*`, E14.md): it is created by its init tests (script conditions), falls with its parachute (`SA_ETAT_Fall`), may hang on a hook (`SA_ETAT_WaitAccroche`), and its position is persisted in `G+0x1250`. "Periodically": the repeat comes from the script condition tests of `SA_init` (4 test/arg pairs) and the "already enough ammo" rule, not from a timer in code [L].
