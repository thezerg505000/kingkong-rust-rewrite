# E13 Destructible structures
## Behaviour
Three destructible families are confirmed: (1) `IOB_*` wooden barricades with staged pieces and thresholds (documented in `E08.md`, ported as `companions::Obstacle`); (2) `ode_*` physics structures (scaffolds, gates, supports built from a zero-terminated list of physics pieces `this+0x14+4i`): they react to pafs (`ode_exec_gestion_paf_externes`, external pafs of flag 0x100000), can be set on fire (E01), have "stability" checks (`ode_exec_gestion_instabilite`), vases (`ode_exec_gestion_vase`) and sounds; a piece whose coordinate difference to a reference object (`this+0x9d4`) exceeds `this+0x9d8` is frozen: physics off, flags 0x600000 cleared, piece state `this+0x4b8+4i = 5` (`ode_state_active@0x6a2e70`; which axis is [L] x); (3) `btode_*` breakable trees (`ODE_BreakTree@0x6a8360` registers 5 key handles; `btode_bhv_TreeHitPAGTimer@0x6a9b20`: up to 8 sub-pieces get hit-flag set for `this+0x910+4i` seconds then cleared; the behaviour ends when none is active).
## Code
`ode_structure@0x6a12f0`, `ode_state_init@0x6a1360` (saved "already destroyed" flag via `fn@0x440500(...,0,0xc9,0x5dc)`: if destroyed, the pieces are removed at init), `ode_state_wait@0x6a1980`, `ode_check_trigger@0x6a1dd0`, `ode_state_active@0x6a2e70`, `ode_state_end@0x6a2ce0`, `btode_*@0x6a83d0..`, `ode_exec_gestion_paf_externes@0x6a4250` (pieces within reach: pafs forwarded to objects in reach (max 50 queried) via `Msg_SendPaf(0x100000, 1e-4 key, strength = this+0x53c+4i)`, an object only receives a stronger paf than the one it already got: array `+0x5c0/+0x604`, 8 entries).
## Numbers
Thresholds are per-instance data: `this+0x53c+4i` (paf strength per piece), `this+0x9d8` (freeze distance), `this+0x910+4i` (tree hit duration) [C structure, values not decoded]. Barricade numbers in E08.
