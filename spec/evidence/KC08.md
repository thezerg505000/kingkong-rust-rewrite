# KC08 Bite
Main document: `spec/evidence/KC06.md`. **Status: no Kong-side bite was found.**

## Behaviour (what the game does)
There is no function or state called bite on Kong's side (`kb find (?i)bite|mord` returns only creature-side states:
`PNJ_Scolo_ETAT_KKBite`, `KR_exec_bite`, `PNJ_Raptor_exec_bite`, V-Rex jaw modes). Candidates for the manual's "bite during suitable combat
interactions": (1) the grab-state strike on a held creature (anim 0xa2 after frame 0x12: class 9, damage 10), (2) the jaw-break finisher
(KC11), (3) a move inside the V-Rex grab protocol (message kinds 0x16/0x17/0x18/0x21..0x23, KC12). Which animation is a bite is only in the
Kong animation bank (names not in the exe). Decision `[G]`: KC08 is implemented as the grab-state strike (item 1), nothing else.
