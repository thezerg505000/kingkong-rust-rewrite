# AN11 Protected traversal (Kong transports Ann through hazardous environments)
Main doc: `AN01.md`.

## Behaviour
Hazards are the same hits as in AN04, so "protection" is Kong being the carrier: carried Ann follows Kong's hand through any terrain (parented pose, `grabbed_KK`), and Kong's climbing/jumping states run with the carry flags set. Kong can climb with Ann in hand: the wall states (`k_ETAT_walling`, `k_ETAT_climb_remonte_rapide`, `k_ETAT_accroch_mur`) contain no carry test, and `k_ETAT_jump@0x8c6690` only re-queries the hand slot; the column climb `k_ETAT_colonne_exec@0x8eb890` requires the hand to be free at its start (`+0x318 == 0`), which is why the game uses the shoulder mode (`Univers+0x890c != 0`) for traversals [L]. In shoulder mode `k_reflex` keeps Ann attached via query mode 5 and the held-object message category stays valid across states, so Kong may move through water, up walls and across gaps with her; on losing the query (`handle invalid`) `+0x318` is cleared and she returns to `follow_network`.
Shoulder mode vs hand mode: hand -> `Kong+4 = 1` (explicit carry flag) and clips 0xd2/0xd4/0xd5; shoulder -> no `+4` flag and clip 0xd3 [C].
