# S07 Spear embedding
## Behaviour (what the game does)
A spear that hits a stick-class surface or a creature with durability left embeds: its wear counter grows by 2, it stops (speed, gravity, scale vectors zeroed) and is placed `hit_point - axis*0.6`.
If it hit a moving body it is attached: `Javelin_Plug`@0x87e7f0 re-derives the world position/axis every frame from the hit object's transform and the stored local offset, so the spear rides the creature.

## Code
- `Javelin_launch`: stick branch requires `local_30` (stick-class hit), `this[0x86] < this[0x8c]` (wear < max), and the collider not model `DAT_00b9a088`; then `this[0x86] += 2` for types 0/1 [C], position `hit - axis*0.6` [C],
  local offsets stored: `this[0x43..45]` (position), `[0x46..48]` (axis), `[0x49..4b]` (up) in the hit object's frame via `fn@0x41cbf0` (world->local) [C]; `Dyn_SetSpeed(0)`, `Dyn_SetAcceleration(0)`, `fn@0x4340b0(0)`, `Dyn_SetScale(0)` [C]; hit object `this[0x42]`, bone `this[0x41]`.
- `Javelin_Plug`: each frame `pos = hit_obj.pos + LocalToWorld(this[0x43..])`, orientation from the stored axis/up; `Javelin_Plug_testSIG`@0x87f4b0 destroys the spear when its host is destroyed/flagged (bit 1 of `fn@0x415680`).
- Embedding in a creature spawns blood/impact FX `Javelin_GFX_Impact`@0x87ed80; the creature receives the 0x38d1b717 hit message (S06). Whether it dies is the creature's own state machine.
