# AN06 Cooperative puzzles
Main doc: `AN01.md`.

## Behaviour
Level scripts put Ann in the `action` state (id 0xb) and write an action id into `Ann+0xfe0`. `KAnn_ETAT_action@0x5fd350` dispatches it. These are the cooperative tasks:
* 1 Teleport (`KAnn_exec_action_teleport`): snaps her to a marker object (`Ann+0x2c`) and aligns her to its facing; plays idle clip 10 (0x4b with javelin).
* 2 Javelin get (`..javelin_get`): only when she has no javelin; walks to the stock object, plays clip 0x32, spawns a javelin object (`fn@0x4120b0`), decrements the stock nibble (`obj+0x4c & 0xf`, 0xf = unlimited), sets `Ann+0x5c = 1`.
* 5 Set fire (`..javelin_set_fire`): only with a javelin; clip 0x5f, at clip frame > 0x41 the javelin object's `+0x3c` is set to 1 (burning), then the action completes (`Ann+0x1044 = 1`).
* 3 Javelin throw (`..javelin_throw`): faces the target (`+0x1018`), plays clip 0x5c, on the throw frame computes a ballistic launch (`fn@0x56a7c0`, speed-limited by a 20-unit parameter), launches the javelin (`fn@0x415d40`), sets the three `fn@0x4263b0(.., 0x7d/0x7e/0x7f, 3)` marker flags, sets the stock nibble down by 1, speech `0x87003fdd`. First throw 0.5 s after acquiring a target, then `Rand_Range(4, 7)` s between throws (`Ann+0xfd0` timestamp, `+0xfd4` interval).
* 4 Cache / 7 interaction_cache: hide (`KAnn_exec_action_cache`, `..interaction_cache`): moves her behind cover and plays hide anims; speech lines `0xd0005b34`, `0xd0005aca` when a threat (beacon class 2/3) stays >2 s / >8 s (`Ann+0x1070` timer); camera nudge `fn@0x7d49a0(0.1, 35, 0.1, 20, 0.2, 1.1)`.
* 8 Colonne (`..colonne`): leans against a column object (`Ann+0x2c`), clip 0x1d, blends toward it at 10/s.
* 9 Sacrifice (`..sacrifice`): stands on the marker and plays clip 0xdc (the bait/offering scene), acceleration zeroed.
* 6 / target is a KSpider: `attack_GEST` family (AN08).
Fire sources: the javelin only ignites by playing the set-fire clip at a fire (the level places the Ann action at the fire marker); no separate "fire source" test exists in `KAnn_*` [L]. The drop trigger `TrigExec_KAnn_Drop_Javelin` (`Univers+0x8920 = 1`) makes `KAnn_exec_javelin_drop` destroy her javelin on the next reflex [C].

## Code
As listed (all `KAnn_exec_action_*@0x5f1870-0x601dc0`). `KAnn_ETAT_action` picks the branch by `Ann+0xfe0`; it also uses `Ann+0xfec` (interrupt), `+0xff0` (action timer), `+0x3c` (action countdown, `-1e14` = none) [C].

## Rust
`AnnAction`, `next_throw_interval`, `decrement_javelin_stock`; tests `javelin_numbers`, `state_ids_round_trip`.

## Gaps
Which levels use which action id is level data. Javelin damage to enemies is on the javelin side (`Javelin_*`, J-group docs). The levers/devices Ann "uses" besides the javelin/fire are not separate code paths (they are triggers) [gap].
