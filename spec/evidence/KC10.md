# KC10 Knockdown
## Behaviour (what the game does)
Kong knocks the V-Rex down by taking its Life gauge to 0. At 0 the rex plays a fall and lies in
`KT_ETAT_KO_au_sol` for ~4.75 s (5.0 - 0.25), vulnerable and open to the finisher if wounded; it then gets
up with at least 20 life. Which of Kong's hits hurt, and which "knock down" (feed Kong's feedback), depends on hit flags
and on fury. Full details: `spec/evidence/B02.md` (Life gauge, check_paf, transition table).
## Code
* `KT_exec_check_paf@0x49e580`: damage rule and knock-down capability (`fn@0x559f20@0x559f20`).
* `KT_TRACK_reflex@0x49a430`: life <= 0 in idle/fight states -> `Rex+0x2e0 = 5.0` -> `GOTO(KO_au_sol)`.
* Other KO sources: charge/derap/projectile impact (20.0 damage then KO if 0), `grabbed` (throw at 0 life, 2.0 s),
  `JumpAttak` landing (5.0 s, or 0 if life 0), `chute` landing.
* `KT_ETAT_KO_au_sol@0x4aaa00`: hold time `Rex+0x2d8 = Rex+0x2e0 - 0.25` (2.0 s if `Rex+0xa3c != 0`, i.e. KO'd before),
  anims 0x1d/0x1e/0x20/0x21/0x22/0x3c/0x8e by how the rex fell; wounded flag `Rex+0x4e8` set on entry (when `Rex+0xa3c==0`) is the
  window in which the finisher is accepted; exit revives to 20 life (`fn@0x556780`).
