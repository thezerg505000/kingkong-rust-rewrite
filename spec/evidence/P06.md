# P06 Chapter replay
## Behaviour
Replay mode is `G+0x5670 != 0`: cumulative profile counters (G+0x5e6c..0x5e80) are not incremented, the chapter loadout is applied (P07) and the replay score is saved only if it beats the stored best.

Stats_OnPlayerDeath@0x52f240 (G+0x5670 gate), ES_EnterMap@0x6f18d0, fn@0x4da570 (IntMIG_loop replay start), fn@0x4e0ee0@0x4e0ee0 (best score save) [C]. uni_go diverts to menu map 3 when target differs in replay [C].
