# AN05 Ann navigation
Main doc: `AN01.md`.

## Behaviour
Ann's default state is `follow_network` (id 9, slot-2 initial state in `KAnn_TRACK_init`, `DAT_b991ac`). She moves along a level-authored follower network (`NET_Follower`, waypoint graph) toward goals set by the level (Kong's position/target, a fire, a javelin cache). The string `"Ann has reached the end of a network, or has to get fire but has no javelin !!!"` shows the two failure cases: network end, or the scripted fire task without a javelin (she then needs `JavelinGet`). If the init flag `Kong.flag 0x1000` is set she starts in `action` instead. The follower network speed is 2 m/s (cruise `Ann+0xfc4 = 2.0`) switching to 4.0 (`+0xfc4 = 4.0`) when she must catch up [C stores, role L]. Facing turns by +/-pi/2 steps (`fn@0x41d730(.., +-1.5708)`) while sidestepping, and slows within 0.8 of a waypoint heading cosine.

## Code
`KAnn_ETAT_follow_network@0x5fb530` (6824 bytes, 44 callees): handles the network step, the `serveur_get` slots, fear (`Univers+0x8908`), shoulder mode, `Check_Paf_on_Network` global `+0x891c`. `KAnn_exec_dyn_on@0x5fd000` enables dynamics with flags `0x8009014`, gravity-like acceleration `(0,0,-20)` and drag 0.45 (`fn@0x433a70(Ann, 0x3ee66666)`... in `init` 0.45 appears at follow_network l.791) [C]. `KAnn_CALLBACK_set_pos@0x5f2a30` (12 KB) is the position post-processing (collision, ground snap) [L].
`KAnn_exec_set_obbox@0x5f5af0` builds her oriented bounding boxes (values +/-0.05..0.4 m) [C].
`KAnn_exec_IK_suivi_regard@0x5f7640`, `KAnn_exec_IK_snake@0x5f8270`: head-look and a "snake" chain IK (hair/spine), presentation only.
