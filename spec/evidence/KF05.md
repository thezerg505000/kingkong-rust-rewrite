# KF05 Increased resilience
## Behaviour (what the game does)
There is no flat damage reduction in the hit code (`k_exec_detect_paf@0x8c3fc0` subtracts the packet damage from
Kong's Life gauge `Kong+0x1aa0` unscaled). Fury protects Kong in four ways:
1. **Cannot die**: when Kong's life reaches 0 with fury on, life is reset to 10.0 (`k_reflex`); without fury the
   0-life state starts a 10 s "last stand" in which one more hit with < 5 s left kills (state code 0x1f) and a hit
   with >= 5 s left cuts the timer to 5 s.
2. **Cannot be finished by the rex**: the rex's own finisher (`KT_ETAT_I_Finish` via `fn@0x555e10`) requires Kong
   wounded and `fn@0x6038a0(kong) == 0` (not in fury) twice in a row, or Kong in last stand (`Kong+0x1fc8`).
3. **Grab struggles tilt**: Kong's mash decay is x0.5 with fury (`k_ETAT_grab_mashing`) and the pull-force decay in
   grabs/jaw-break is 3.0/s instead of 20.0/s (`k_ETAT_grab`, `KT_ETAT_Finish`).
4. The fury timer is *consumed* by hits (2.5/5.0 s), so the shield wears off under pressure.
## Code
`k_reflex@0x8a4360` (+0x8a4... life==0 block; `fn@0x770aa0(Kong+0x1aa0, 10.0)`), `k_exec_detect_paf@0x8c3fc0`,
`k_ETAT_paf@0x8c24a0`, `k_ETAT_grab_mashing@0x8cca60`, `k_ETAT_grab@0x8dae10` (decay `20.0`/`3.0` at the `Kong+0x7c4==0` test),
`KT_ETAT_Finish@0x4b98d0`, `fn@0x555e10`.
## Numbers
revive life 10.0; last stand 10.0 s / lethal below 5.0 s; mash decay x0.5; pull decay 20.0 -> 3.0 [C].
