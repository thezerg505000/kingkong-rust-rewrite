# AN03 Place Ann
Main doc: `AN01.md`.

## Behaviour
Pressing grab while carrying (`k_TEST_Grab@0x8eaaa0`: `+4 != 0 || +0x318 != 0` and the target lacks flag 0x20) runs `k_ETAT_grab_ANN` in its put-down branch: Kong plays clip 0xd2 (or 0xd3 when she rides the shoulder), then 0xd4/0xd5; once `Kong+0x68 >= 0.3` (0xd5) or `>= 0.6` (0xd4) it clears the carry flags (`+4 = 0`, `+8 = 0`, `+0xc = -1`) and probes for a clear spot behind Kong. Probe: for `c = 0..3` a raycast of length 5.0 from `Ann - c*axis` along the reverse axis (`Raycast_Object(.., 5.0, 0xffffffff, 0x20, 0, 1)`); the first clear probe is used, probe 3 is accepted without a test. Ann is then released (`fn@0x43ab50(Ann, msg)` sends the release message) at that offset and returns to `follow_network`. The hand-over ends with `ANIM_IsEnded` which clears `Kong+0x18c8`. "Valid position" is therefore only: not blocked by geometry (collision mask 0x20) within 0..3 m behind Kong [C, mask meaning L].
