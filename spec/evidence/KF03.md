# KF03 Increased aggression
## Behaviour (what the game does)
With fury on, every Kong animation plays 1.25x faster, so attacks come out faster; hits are also heavier
(KF04). Details: `spec/evidence/KF01.md` (section Effects).
## Code
`k_ETAT_main@0x89a120` tail (disasm 0x8a4064-0x8a40b4): `fn@0x4258b0(self,0, ftol(fn@0x4244e0(self,anim)*1.25))`
when `!IsZero(Kong+0x7c4)`, else the unscaled speed.
## Numbers
1.25x (`_DAT_00a89194`) [C].
## Data
Per-animation base speed byte in the anim channel (`fn@0x4244e0`), not read.
## Rust
`kong::fury::{FURY_ANIM_SPEED_MUL, Fury::anim_speed_mul}` (test `damage_doubles_and_becomes_heavy`).
## Gaps
Other speed effects (movement speed, turn rate) were not found; only the animation rate is scaled.
