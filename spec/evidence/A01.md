# A01 Idle (raptor view; one species)
Main doc: `spec/evidence/X02.md`. The engine class `PNJ_Raptor_*` serves species 0xe (raptor), 0x10 (Jack-level V-Rex), 0x16 (compies); this is how the **raptor** (0xe) does it.

## Behaviour (what the game does)
`ETAT_ATTENTE` (state 0) is the idle/decision hub: it stays up to **1.0 s** [C `PNJ_Raptor_ETAT_ATTENTE@0x839e40`, `+0x1404 <= 1.0`] while pathing mode 2 and `select_action` run (idle gait, animation ids 2/4/0x66 with look-around timers `+0x218c` rand 3..5 s / `+0x2190`, `select_action@0x83a950`), then goes to VALA (patrol) if there is no target. Idle animations are chosen by `select_action`; speed eases to 0.

## Code
