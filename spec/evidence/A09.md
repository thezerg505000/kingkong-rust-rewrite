# A09 Recovery (raptor view; one species)
Main doc: `spec/evidence/X02.md`. The engine class `PNJ_Raptor_*` serves species 0xe (raptor), 0x10 (Jack-level V-Rex), 0x16 (compies); this is how the **raptor** (0xe) does it.

## Behaviour (what the game does)
After a bite and after every flinch the raptor gets a 3.0 s "requin" (shark) wait: it backs off into circle mode and cannot bite again until the timer reaches 0. Flinch states themselves last for the length of their animations (SLIDE/FALL/FLY).

## Code
`ETAT_MORD@0x84d860` exit, `ETAT_PAF_*`, `exec_check_requin@0x851550`, `exec_select_action` (timer countdown `min(t,dt)`).
