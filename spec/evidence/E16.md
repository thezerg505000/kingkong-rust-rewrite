# E16 Narrow passage safety
## Behaviour
There is no "narrow passage" rule in code. Large creatures are kept out of places by data: the navigation grid/network (`fn@0x427b90` tags that block areas, e.g. `IOB_TAG_OFF` removes the barricade tag when destroyed, `Trap_QS_DETECT_c` adds +0x40 tags around quicksand), per-species collision shapes, and territory masks (`Raptor_TerritoryInMask@...`, V-Rex species 0x10 uses the same class as the raptor with different scale/size). The Jack-level V-Rex cannot reach spots whose nav cells are not part of its way network ([L]: `PNJ_Raptor_exec_way_*` use the network, see X04).
