# S06 Spear impact
## Behaviour (what the game does)
Every frame `Javelin_launch` casts a ray from the previous position to the new tip (`pos + axis * this[0x3d]`) with `Col_RaycastFromObject`@0x42dc10, reads the hit material (`Col_LastHitMaterial`@0x42dfd0),
hit object (`Col_LastHitObject`@0x431b20) and collision bone (`Col_LastHitBoneIndex`@0x431990), then classifies it. Creatures get a hit message (id 0x38d1b717, built by `Msg_BuildHit`@0x6e3e70)
with the damage; world surfaces make the spear stick.

## Code
- Material classes: material 0 or > 7 becomes 1, or 5 when the hit has a bone index. 0,1,2,6 = stick; 3,7 = glance (impact GFX only); 4 = pass through and re-cast (max 2 passes), sets `this[0x3e]=0` (fire out) [C]; 5 = creature part, stick [C].
  Meaning of the material numbers (4 = water) is [L] (the stop-in-water code in `Javelin_endofmove` and fire-out agree).
- Damage: `dist_sq = |pos - this[0x72..74]|^2` (distance from the creation point, NOT from Jack); `R1 = Univers+0x46b0+4w`, `R2 = Univers+0x4704+4w` with w = 6/7/8; `dist_sq < R1^2` near, `< R2^2` mid, else far;
  value `_ftol` of `Univers+0x4804+12w+4b` (operand dropped by the decompiler, same as `Weapon_DamageAtDistance`@0x53a370 [L]); `+10` while `this[0x3e]` burns [C]; flag 0x40 on the javelin zeroes the stick flag [C].
- Embedded hit: full damage message to the collider unless the collider is the thrower itself (player-class actor == main actor); then `this[0x4c] = -1.0`.
- Not embeddable (wear >= max, or collider model `DAT_00b9a088`): `local_fc = local_fc / 2`, message sent, spear rebounds: velocity x 0.1 reflected about the surface normal (`v - n * 2(v.n)/|n|^2`), gravity (0,0,-20), state `DAT_00b9a090` [C].
- Raptors in the world react to nearby javelins (`PNJ_Raptor_exec_check_javelin`@0x869370) by raising a +0x130 timer on the javelin [C] (dodge, details not isolated).
