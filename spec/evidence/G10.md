# G10 Damage by weapon
## Behaviour (what the game does)
A firearm hit does one of three damage values depending on how far the target is from the
shooter: near, mid, far. The band edges and values are per weapon. A one-hit cheat flag makes
every hit return 1000.

## Code
- `fn@0x53a370(weapon, dist_sq)` @0x53a370 (named `Weapon_DamageAtDistance`), 200 bytes, caller `H_callback_tir`.
  Verified on the decompiled C and on the bytes (x87 `fcomp; fnstsw; test ah,0x41; jnz`):
  - `(G+0xbf0) & 2 != 0` -> returns 1000 (`mov eax,0x3e8`) [C]
  - `R1 = float[G+0x46b0+4w]`; `if R1*R1 <= dist_sq` go to mid else near = `float[G+0x4804+12w]` [C]
  - `R2 = float[G+0x4704+4w]`; `if R2*R2 <= dist_sq` far = `float[G+0x480c+12w]` else mid = `float[G+0x4808+12w]` [C]
  - the chosen float goes through `fn@0xa763cc` (CRT `_ftol`, truncating) so the result is an int [C]
- Argument 2 is a SQUARED distance: callers pass `fn@0x4150e0(shooter, target)` = squared distance between
  the two objects' positions (matrix +0x30 translation), not the ray length [C]. Callers: all four cases of `H_callback_tir`.
- Table written at start-up by `uni_init.ofc` statements 769-832 (ova offsets + 4 = exe offsets).

## Data
`code/ova/uni_init_all.txt` lines 769-832: `i<w> VAR1@46ac/22 f<R1>`, `@4700` R2, `@4658` range, `@4754` clip,
`i<w> i<b> VAR2@47fc/22 <dmg>` damage. The damage array's ova address (0x47fc+4+12w+4b) is 4 below the
address the code reads (0x4804+12w+4b); the row/column order is unambiguous (monotone near>=mid>=far), so
the value assignment is kept; the 4-byte difference is probably a 2-D array header [L].
Object holding the table is the global-state object with key 0x3d0098b3 (`DAT_00b990d8`/`b99358`), see `docs/KNOWLEDGE_BASE.md` (kb_annotate).

## Gaps
- Player health scale (what 8 damage means for NPCs/Kong) is not in this function.
- `pointblank` column (`@47a8`, values 1,2,1,0,0,0..) is never read by decompiled code; meaning unknown.
- Distance is object-to-object (`fn@0x4150e0`), so a large target is measured from its origin, not the hit point.
