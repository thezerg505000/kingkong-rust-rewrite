# P02 Character switching
## Behaviour
Whether a chapter is played as Jack or Kong is its level-table type (2 = Kong). The Jack/Kong split drives which stat set and score formula is used.
## Code
- fn@0x4e0dc0@0x4e0dc0 returns true for Kong ids {304,504,601,705,1002,1402,1703,1901,2001,2002,2003,2004,2100} [C].
- Kill_Credit@0x52f950: `fn@0x43f8e0(player, DAT_00b9913c)!=0` selects Jack classes, otherwise Kong [C].
