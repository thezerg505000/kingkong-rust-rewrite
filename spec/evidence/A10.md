# A10 Hit reaction (raptor view; one species)
Main doc: `spec/evidence/X02.md`. The engine class `PNJ_Raptor_*` serves species 0xe (raptor), 0x10 (Jack-level V-Rex), 0x16 (compies); this is how the **raptor** (0xe) does it.

## Behaviour (what the game does)
Damage size picks the reaction: light -> PAF_SLIDE, medium -> PAF_FALL, heavy -> PAF_FLY (knockback 10/10/12 m/s along the hit direction). Thresholds 8/11/20 (alpha 15/20/40) with an accumulator (10 / 30) for small hits. Headshots (bone 0 / 0xf5) x2 for variants 0/1; alpha takes -5 on body hits. Full table in X02 "Hit reception".
