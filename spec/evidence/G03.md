# G03 Manual reloading
## Behaviour (what the game does)
Reload (R1) is refused if the magazine is full. Otherwise the reload animation plays and, when it ends,
rounds move from reserve to the magazine. The shotgun loads one shell per reload cycle.

## Code
`H_exec_loading_weapon` @0x5ccc70 (707 lines), `w = G+0x3344+4p` (held weapon):
- `if mag[w] == clip[w]` (G+0x342c+0x48w+4p vs G+0x4758+4w): no reload (may play a "full" message) [C]
- reserve empty and not already reloading: plays the "empty" sound id per weapon (0x37, 0x41, 0x4b, 0x55 for w=1..4) [C]
- at the end of the animation (`piVar1[0x444] < 0.0`) and in the early-out branch (anim frame > 0x19 for Colt, > 0x5a for Tommy): [C]
  `avail = reserve[w]` ; `if (w == 3) avail = 1` ; `if (clip < avail) avail = clip` ; `n = clip - mag` ; `if (avail < n) n = avail` ;
  `mag += n ; reserve -= n`
- shotgun additionally loops (`G+0x3aac`, `G+0x3504`) until full or interrupted [L].
