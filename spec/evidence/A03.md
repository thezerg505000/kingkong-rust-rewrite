# A03 Target detection (raptor view; one species)
Main doc: `spec/evidence/X02.md`. The engine class `PNJ_Raptor_*` serves species 0xe (raptor), 0x10 (Jack-level V-Rex), 0x16 (compies); this is how the **raptor** (0xe) does it.

## Behaviour (what the game does)
See X02 "Perception". Sight: horizontal cone test, narrow cone 30 deg half angle / 10 m (+1 m near radius), wide 262 deg field of view / 100 m with a line-of-sight ray for humans (Jack, companions); hearing: sound events inside their own radius, shots passing within 5 m. Results are flag bits in a 20-slot list.

## Code
`exec_check_vision@0x83f130`, `fn@0x6e58c0` (`Perception_ConeTest`), `fn@0x52edf0` (`Perception_LineOfSight`), `exec_check_sound@0x8478d0`, `exec_check_shoot@0x85b0a0`, `fn@0x47e180` (register slot).

## Numbers
| value | where | conf |
|---|---|---|
| narrow cone cos 0.866 (`0x3f5db3d7`), range `+0x210c` = 10.0 m (V-Rex 8.0), near radius 1.0 | check_vision, init | C |
| wide cone cos -0.653 (`0xbf275526`), range 100.0 m, LOS mask `0x80000001` | check_vision | C |
| shot detection: closest approach < sqrt(25) = 5 m (V-Rex 8, compy 4) | check_shoot | C |
| sound: distance < event radius (`Life_GetMax` of the event) | check_sound | C |

## Data
Event radii are produced by whoever makes the noise (weapons, doors) - not read here.

## Rust
`creatures::raptor::cone_test`, `Perceived`, flag consts.

## Gaps
The cone-edge capsule branch of `fn@0x6e58c0` (taken when the target is just outside the cone) is not ported; the vision test is evaluated in the horizontal plane.
