# E05 Fire-based barriers
## Behaviour
Vegetation that blocks progress is flammable ground (material 8) plus, where the barrier is solid, a navigation "tag" block. A grid fire burns the cells (burn-out leaves state 0x80 = burnt, never re-ignitable) and the persistence flag (`SGF_CP`, id `0xc9/0x5dc` record) keeps the burnt patch after a reload. Obstacles that are solid objects (wooden barricades) are the separate `IOB_*` system (E08): they are not burned, they are broken by hits. Thorn bushes as walls are level data (ground grid + trigger tests such as `TrigTest_PositionGrilleEnflam`), there is no "thorn bush" class (`KInteractive_Shrub@0x6a80a0` only registers a model key `0x4d00161a`, no logic of its own).
## Code
`SGF_*`, `TrigExec_Burn`, `TrigTest_PositionGrilleEnflam` (E01); tag blocking `fn@0x427b90`/`IOB_TAG_OFF` (E08), quicksand `Trap_QS_DETECT_c@0x6ee6a0` uses the same tag call with +0x40/-0x40.
## Numbers
As E01. Burn-out leaves a permanent 0x80 state [C].
## Data
Which cells/trigger bind a barrier: level data.
