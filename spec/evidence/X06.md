# X06 Smaller millipedes (`PNJ_Scolo` types 1 and 2)
Status RESEARCHED. Main doc: `X05.md` (class, states, code).

## Behaviour
The "smaller faster multi-legged threats in groups" are Scolo size types 1 and 2: same state machine as the megapede but smaller, with less life and higher speed factor. Groups come from level spawners (`Spawner_*`); each instance picks its type from level data.

## Code
`PNJ_Scolo_exec_settings@0x826150` (types), `PNJ_Scolo_Init@0x8074d0`, states as X05.md.
