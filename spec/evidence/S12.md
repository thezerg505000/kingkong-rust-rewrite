# S12 Flaming spear
## Behaviour (what the game does)
A spear is ignited by message 0x7d2 (`this[0x3e] = 1`, timer 10 s, flame GFX `Javelin_GFX_fire1`@0x87fa70). Sources found: (1) the level script message 0x186a7 sub 5 with a weapon code above 100 gives Jack weapon code/100 already lit (`G+0x4520+4p = 1`) (`H_exec_ch_msg`@0x5b3d70);
(2) a resting spear whose tip is inside a fire zone ignites (tested once per second); (3) a burning spear picked up keeps burning (`G+0x4574 -> G+0x4520`); (4) thrown while lit, the ignite message is sent right after the launch.
Water (hit material 4) puts it out. Fire also ends by itself after 10 s.

## Code
- `Javelin_waittaken`: every 1.0 s (`this[0x84]`) for a stuck spear with `this[0x8e]` set and not burning: `Fire_PointInFireZone`@0x6e3210 (point vs sphere type 0 / capsule type 1 over objects of list 0x17, uses radius `fn@0x43c430(.,2)`) at the spear tip (`pos + axis/2` when wear < max); true -> `this[0x3e]=1`, `this[0x7a]=10.0` [C].
- `H_ETAT_IA_lance`: lit throw: `G+0x4520+4p == 1` and (weapon 5 or Jack `[0x61e]/[0x645] != -1`) -> message 0x7d2 [C]. `Jack_DropHeldThrowable`: lit item dropped is ignited too [C].
- `Javelin_launch`: material 4 pass-through clears `this[0x3e]`, removes the flame effect `this[0x5c]` [C]. `Javelin_GFX_fire1`: flame trail between last and current position, timer `this[0x7a]` (+0x1e8) decremented by dt; at <= 0 clears `this[0x3e]` (+0xf8) [C].
- Ann's variant `KAnn_exec_action_javelin_set_fire`@0x5ffb50 (anim 0x5f frame > 0x41 sets the flame) is Ann-side, not Jack.
