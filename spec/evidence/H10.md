# H10 Checkpoint restart (death flow)
## Behaviour
Jack status 3 -> `H_TRACK_joueur` death camera phase (`this[0x2f24]` timer: >0.5 s death camera mode, >1.5 s body frozen, >3.0 s goes to state 0x2bd) -> `H_ETAT_IA_mort@0x5a3e80`: fade-out object (`fn@0x7d47c0`, colour black), body/ragdoll handling, effect message code 4 every frame (`Msg_SendJackScreenFx`). When the state timer `this[0x2be]` exceeds 4.0 s (and the fade is done or `this[0xeca]` <= 0.5) it calls `Stats_OnPlayerDeath@0x52f240` (death counters; `G+0x4dc8`++ for cases 0/1) and `fn@0x405130` (sets `DAT_00bdf57c=1` message-queue flush and `DAT_00b0da28 = 30` frames, returns 3); `fn@0x8ff020` counts the 30 frames down and then `fn@0x405160(0,-1)` flags every GST object for reload (`|= 0x4000000`) = reload from the last checkpoint (the checkpoint itself is `ES_CheckPoint@0x6f49a0`). Fallback: 8.0 s in the state also restarts. If Ann revives Jack (status back to 0) before that, the state returns to normal (state 5).
## Code
`H_ETAT_IA_mort@0x5a3e80` (lines 200-260 entry, 490-700 Jack branch), `Stats_OnPlayerDeath@0x52f240` (cases 0/1: `G+0x4dd0`, level counter `G+0x1e08+0x50*k`, `G+0x4dc4` total, `G+0x4dc8` since map change; cases 2/3: per-level only), `fn@0x405130@0x405130`, `fn@0x8ff020@0x8ff020`, `fn@0x405160@0x405160`, `fn@0x405440(0,slot)` stores the respawn slot at `+0x1e8`. Consumers of `G+0x4dc8`: Jack wound tiers (H02), `TrigTest_NbrOfDeath@0x46b0b0` (level scripts), `GEX_Init@0x6c5aa0` ("NeuNeu" easy mode if `4dc8 - 4dcc > 2`; `fn@0x548940` "Exploit" mode bumps `4dcc`).
`G+0x4dd4` is a menu-lock timer (5.0 s set here, 30.0 by Kong/Ann death, read in `IntMIG_wait`). `G+0x4df4/4df8/4dfc` ("death shield") are only written (1.0) in `H_TRACK_init@0x5786d0`, never read: dead data, not a shield [C: grep of whole KB].
