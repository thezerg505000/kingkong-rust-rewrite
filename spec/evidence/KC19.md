# KC19 Kong-level V-Rex hit reaction, knock-back and clip ids
## Behaviour
Every blow that lands on the KT rex (Kong's fists, Ann's hits, thrown objects) goes through `KT_exec_check_paf`
(damage, counters) and, unless it knocks the rex out, `KT_ETAT_paf`, which plays a reaction clip chosen from the
blow's class and direction, shoves the rex along the blow and gives it a yaw kick. A new blow while reeling
restarts the reaction.
## Code [C]
* `fn@0x0055a020` (called on entry to `KT_ETAT_paf@0x4a1160` and again for every new hit, `Rex+0x2a4 != 0`):
  * life <= 0: no clip, `Rex+0x2e0 = 5.0` (KO timer), knock flag `+0x2cc = 1`, sound 4.
  * flag 0x40 -> KO path (`+0x2e0 = 0`, `+0x2cc = 1`). Pending `+0x2ec` -> clip 0x27.
  * class 0x10 -> 0x6c (sound 3). class 8 -> 0x33 (sound 4; turns to face the attacker; sets `+0x2cc`/`+0xa3c`
    when `+0xa38 < 3`). class 2 -> 0x67 / 0x64 / 0x65 / 0x66, class 1 -> 0x6b / 0x68 / 0x69 / 0x6a (sound 3) by
    `dot(Obj+Y, h) > 0.866` / `< -0.707` / `dot(Obj+X, h) <= 0` / else, h = attacker -> rex (`Rex+0x2ac`).
  * clip play length = frames x `rand(0.9, 1.9)` (`fn@0x0041c450`, `fn@0x004258b0`) [L: read as play length].
  * `Rex+0xae8` (copied to `+0xaec`): 0x1d/0x27 0.3, 0x33 0.475, 0x64-0x67 0.06, 0x6c 0, otherwise 0.2 (0.1 when the
    attacker is the fight target).
* Axes [L]: the KT clips walk toward Jade -Y (kt_0x01 root -6.6 m), so `Obj+Y` is the rex's back and `Obj+X` its
  left; clip 0x65 leans the pelvis toward -X (to the right) and 0x66 is its mirror (TRL 0x3aff809), consistent with
  "blow travelling right -> 0x65". 0x64/65/67/68/69/6b share TRL 0x3afe7eb, 0x66/6a/6c TRL 0x3aff809 (35 f).
* Knock-back: `KT_exec_check_paf` -> `fn@0x006e4970(..., hit vector, 8.0, &Rex+0x5e8, &Rex+0x5f4)`: velocity =
  normalize(hit) x 8.0 (0 for class 0x10), yaw kick `+0x5f4` = -(normalised axis x lever) . hit, sign by the side
  of the hit point along the body axis; `+0x2c8 = 0`. `KT_TRACK_tagon@0x499840` each frame while
  `1 - +0x2c8 >= 0.1`: speed = lerp(+0x5e8, own speed, +0x2c8) (`fn@0x0041d600` is a clamped lerp), yaw +=
  (1 - b) x kick x 3 x dt, b += (1 - b) x min(3dt, 1). Total slide 8/3 m.
* `KT_ETAT_KO_au_sol@0x4aaa00` fall clip: from `JumpAttak` or after 0x15 -> 0x3c (lying loop); from `charge` 0x16;
  from `chute` 0x26; after the slams 0x8d / 0xa1 -> 0x3c; knock flag -> 0x22 (dot(X,h) >= 0) / 0x21; from `grabbed`
  -> 0x1e; else 0x16 (`+0x2dc` -> 0x1d). Then the lying loop 0x3c while the hold clock `+0x2d8 = ko_time - 0.25`
  runs (it only counts down in 0x3c), then the get-up 0x1e; when 0x1e ends the rex leaves KO. A blow while lying
  plays the ground hit 0x20 (back to 0x3c afterwards) and stays down; a blow during 0x1e goes to `paf`; a 0x20000
  blow kills.
* `KT_ETAT_mort@0x4a1cb0`: 0x15 then 0x1c. Roar (`fn@0x00556040`, `KT_ETAT_cri`): 0x24 (at the fight target),
  0x23, 0x6e (wounded). `KT_ETAT_charge`: sound 6 + clip 5. `KT_ETAT_derap`: 0x92/0x94/0x95/0x96. `attente`:
  `+0x888`, 0, 0x60, 0x61, 0x15.

## Gaps
`+0x2cc` from the 0x33 branch depends on `+0xa38` (not identified) -> the sideways KO falls 0x21/0x22 are never
chosen. The hit point that sets the yaw kick is taken as Kong's side of the body [L]. Sound slots 3/4/6 are 07D
bank entries (stand-in: the 03E rex "Trex_take_shoot"). Whether KT locomotion follows the clips' root speed or a
Dyn speed is open (the fight keeps walk 4.0 / charge 14.0 [G]).
