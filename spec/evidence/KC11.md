# KC11 Jaw-break finisher
## Behaviour (what the game does)
When the rex is lying knocked-down **and wounded** (`cur/max <= ratio`) and Kong is within 22 units (height
difference <= 5), the rex offers itself as a finish target (`KT_exec_propose_grab`, message mask bit 8). If Kong
takes it, the rex goes to `KT_ETAT_Finish` (id 0x6c): ~2.74 s of lock-on animation (anim 0x37), then a
**tug-of-war mash**: Kong's pull force against the rex's growing resistance moves an animation cursor. If the
cursor passes the end of the animation the rex dies (`mort`, Kong sends message 0x17); if the cursor falls under
102 frames the rex breaks free (`escaped`, anim 0x39, replies 0x18) and the fight resumes (`fight_KONG`, life
floor 20).
## Code
`KT_ETAT_Finish@0x4b98d0` (rex side), `KT_exec_propose_grab@0x49ee50` (entry offer), `KT_ETAT_KO_au_sol@0x4aaa00`
(accepts message kind 8: `fn@0x6e2e50(&Rex+0x494) == 8` -> Finish, other kinds -> grabbed),
`fn@0x602e40@0x602e40` (Kong's pull value 0..1 by action id 0x352/0x353/0x160/0x15e and anim phase),
`fn@0x6039d0@0x6039d0` (Kong's mash buttons active = `Kong+0xa4 | Kong+0x7c`), `fn@0x6038a0` (fury).
Message kinds Kong -> rex while finishing: 0x15 (mash running), 0x17 (finished); rex -> Kong: 0x16 (won, anim 0x38,
sets `Rex+0x878 = 1`), 0x18 (rex escaped). Kong's own side is `k_ETAT_finish@0x8e3ca0` / `k_ETAT_finished@0x8b5c80`
(not audited).
Per frame (dt clamped to [0.016, 0.048]) once `Rex+0x3b4 >= 2.74`:
```
window = 10.0, or 0.0 if pull - resist < -2.5
if pull < 2.0:  resist = min(resist + 2*dt, 10)
pull  = max(pull - (fury ? 3.0 : 20.0)*dt, 0)
if t < window + 2.74 and kong_pressing:  pull = 3.5 - 0.5*kong_value ; resist = max(resist - 0.5, 0)
cursor += pull - resist
if cursor < 102 (first time):  escape      if cursor > anim_len: win
```
Before 2.74 s the cursor simply follows the current animation frame.
## Numbers
2.74 s, 10.0 s window (+2.74), 102.0 frames, pull 3.5-0.5v, resist +2.0/s (cap 10), -0.5 per press, pull decay 20.0/s
(3.0/s in fury), dt clamp 0.016-0.048, accept radius 22.0, |dz| <= 5.0 [C]. Required presses depend on `anim_len` and
Kong's pull animation (`fn@0x602e40`), i.e. animation data `[gap]`.
## Data
Animation frame counts of rex anims 0x37/0x38/0x39 (rex animation bank) and Kong's finish animations: not read.
## Rust
`kong::vrex::{FinishMash, FinishOutcome, finish_accepts}`; tests `finish_mash_*`, `finish_accepts_*`.
## Gaps
Frame rate of the cursor units; Kong-side `k_ETAT_finish` (which inputs produce `kong_pressing`/`kong_value`).
The ledger name "jaw-break" for this state is `[L]` (the rex-side anims are 0x37-0x39, the Kong side pulls the jaws).
