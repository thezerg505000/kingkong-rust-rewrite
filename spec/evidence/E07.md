# E07 Light propagation puzzles
## Behaviour
"Bring flame to a new area" is built from the pieces in E01/E06: a lit spear lights an `it_` torch or starts a `TrigExec_Burn` fire; the fire front (grid or `SFX_NET_Fire` line) lights further torches because their `it_loop_off` test also checks burning cells and fire zones near them; scripts read the result with `TrigTest_PositionGrilleEnflam` (is this cell burning) and `TrigTest_MultiGaoActive@0x4656d0` (are all of up to 4 listed objects active) to open the next area. No dedicated "light puzzle" class exists.
## Code
`TrigTest_PositionGrilleEnflam@0x46a360`, `TrigTest_MultiGaoActive@0x4656d0`, `it_loop_off`, `SGF_Propage`, `SFX_NET_Fire_ETAT_Burn`.
## Numbers
`TrigTest_MultiGaoActive`: object list = `param+4` (Jack when 0), `+8`, `+0xc`, `+0x10`; true when every non-empty one has object flag bit 0 set; `param+0x64` inverts [C].
