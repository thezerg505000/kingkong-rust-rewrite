# A05 Target selection (raptor view; one species)
Main doc: `spec/evidence/X02.md`. The engine class `PNJ_Raptor_*` serves species 0xe (raptor), 0x10 (Jack-level V-Rex), 0x16 (compies); this is how the **raptor** (0xe) does it.

## Behaviour (what the game does)
`update_best_interest` runs one fixed priority chain over the 20 perceived slots (cinematic-forced, Jack, whatever just hurt it, other raptors after a bullet hit, corpses, the nearest slot in the narrow cone that no other raptor owns, ...). Jack has no explicit weight against companions except rule 3 and interest value 200 vs 30; corpses are food. Full list in X02 "Target selection".
