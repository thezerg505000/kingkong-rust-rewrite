# W09 Interactive scenery
## Behaviour
Gates, props, structures and fire sources are objects with the interaction protocol (prompt id, flag 0x8000 activation) handled in: doors/pillars (`InteractiveDoor_*`, E09-E11), crates (`SA_*`, E14), barricades (`IOB_*`, E08), levers (E10), torches/lamps (`it_*`, `Xenon_Activate_Light_*`, E06), physics props (`ode_*`, E13), Kong grab/mash objects (`KIGO_*`, `KIMO_*`, E12), bamboo/branch pickups (`Interactive_Bambou`, `ib_*`), traps (`Trap_QS_*`). Each is an AI model bound by a registration function that stores the model keys; behaviour is in the states of that model. The aggregate has no code of its own.
