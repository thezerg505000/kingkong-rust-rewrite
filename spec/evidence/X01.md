# X01 Mini Venatosaurus (compies, species 0x16 of `PNJ_Raptor`)
Main behaviour doc: `X02.md` (the shared class, states, perception, pack rules). This doc isolates the compy numbers. Status RESEARCHED.

## Behaviour (what the game does)
The "galiminus" compy is the same state machine as the Venatosaurus (`PNJ_Raptor_*`, 67 functions `@0x8315a0-0x873412`) with `this+0x20 == 0x16`. Smaller, weaker (3 hp), random scale, bites for 1, hit-reaction pushes scaled by 0.75, wait times after a bite 0.5 s instead of 3 s, herd members share perception arrays (`Compy_PerceptionLoad/Store@0x4855e0/0x485bf0`).
