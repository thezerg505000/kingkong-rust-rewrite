# K06 Climbing (main document for K06, K07, K08)
Tags: `[C]` visible in the decompiled C, `[L]` inferred, `[G]` guess. Offsets are `Kong+0xNNN`. Static analysis of KingKong8.exe only.

## Behaviour
Two ways onto a wall. (1) Obstacle: `k_exec_check_obstacle` raycasts ahead; the measured height `Kong+0x179c` is ignored up to 1.9, vaulted when 1.9 < h <= 11 (`fn@0x8851a0`), and above 11 needs a hotspot, using the climb-up anim 0x104 (combat phase 0xb). The wall must be steeper than 45 degrees (|normal.z| < 0.7071). (2) Climbable walls (vine surfaces) run `k_ETAT_walling` (state 1000) with `k_ETAT_accroch_mur` (0x385, hanging) and `k_ETAT_climb_remonte_rapide` (0x389, quick pull-up, anim 0x4d). Climbing speed is clamped to 13..20 in walling. The wall leap (K08) is a jump with an override reach: 18 m (10 m when the direction test fails), see K04 reach table.
