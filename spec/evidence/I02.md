# I02 One spear
## Behaviour (what the game does)
Jack has three weapon slots: A = held, B = stored, C = parking for the lever item (10). A throwable (6/7/8) always sits in A; at most one throwable at a time. Picking another one first drops the held one. The stored gun goes to B.

## Code / Numbers
`G+0x3344/0x3390/0x33dc + 4p` = A/B/C [C] (`H_exec_read_joy`@0x579f30, `H_TRACK_Reflex`@0x58de70, `Jack_ExchangeWeaponSlots`@0x53a8e0). `Jack_IsThrowableHeld`@0x68b8b0: A in 6..8 [C]. Item 10 is the lever (written with `G+0x4588`), kept out of A/B by moving it to C [C].
Pickup of an id already in A does nothing (stack count refreshed for 8) [C].

`spears::Slots::pickup`; test `slot_rules_pickup_throw_drop`.
