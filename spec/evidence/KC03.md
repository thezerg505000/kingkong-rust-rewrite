# KC03 Shoulder strike
Main document: `spec/evidence/KC01.md`. The manual's "shoulder strike: powerful close-range stunning attack" has no
named function; two candidates exist in the code and the decision below is `[L]`.

## Behaviour (what the game does)
Decision `[L]`: the shoulder strike is the **counter lunge** (phase 6, anim 0x16), the attack that follows a dodge
(dodge button, then attack). It is the only Kong blow that is simultaneously (a) always heavy (class 2, so it stuns /
knocks down the V-Rex even outside fury), (b) invulnerable while it plays (anim 0x16 is in `Kong_IsInvulnerable`),
(c) given an enlarged hit volume (hand scale 4.0 instead of 3.0) and (d) a direct hit on the dodge target
(`Kong+0x1098`) in addition to the sweep. The alternative candidate is the phase-10 contextual strike (anim 0xce): it hits a
proposed target with class 0x20 / damage 2 at frame 0x3c and sends it message 0xf (a "stun / interact" message `[G]`).

## Code
`fn@0x884f60@0x884f60` (starter; `Kong+4 != 0` plays anim 0x1b in phase 1 instead), `k_ETAT_main` phase 6 handler
(0x89c1a9..0x89c7b0: window flag 1 -> `fn@0x88d610(4)` victim scan, ray test `Kong+0x1098`, direct
`k_exec_hit_landed(2, 2, Kong, 0x38d1b717, victim, -1, 10, ..)` at 0x89c3c4, victim list `Kong+0xd34[]`),
`k_exec_zdf_zdc` (volume 4.0 during anim 0x16, restored to 3.0), `k_exec_melee_hit` (anim 0x16 branch),
`fn@0x604370` (anim 6, 7, 0x16 = no damage taken).
