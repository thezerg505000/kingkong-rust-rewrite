# AN08 Companion rescue (Kong can defeat enemies threatening Ann)
Main doc: `AN01.md`; bats `AN09.md`; species docs X05-X11.

## Behaviour
Rescue is implicit: Ann is hit by the enemy's damage packet (AN04) unless Kong kills or distracts the enemy first, and there is a **grab link** that Kong's attacks break. Concretely: enemies that target Ann publish interest in her (rex `KT_exec_fight_actor_select` Kong vs Ann, raptor `KR_ETAT_interact_ANN`, bats `KBC_ETAT_Sol_Interaction_Ann`); Ann herself defends with javelins (AN06) and gestures `KAnn_exec_action_interaction_attack_GEST@0x601dc0`, which routes by the threat's beacon class (`Msg_GetBeaconClass`): spider (`attack_spider@0x601a40`), Scolo (`attack_scolo@0x6005e0`), raptor (`attack_raptor@0x600f90`), bat (`attack_bat@0x600950`), default (`attack_default@0x5fe8c0`). When the abductor (bat `Ann+0x144`, rex `+0x14c`) dies or loses the link, `Handle_IsValid` fails and `grabbed_bat` returns to `follow_network` [C: `if (Ann+0x144 == 0) goto b991ac`].

## Code and numbers
* attack_spider: she jabs while the horizontal distance helper `fn@0x5eee00` is within 2.5..13.0 (outside 13 she idles with clip 0x10; inside 2.5 she steps back with clip 0x103), jab clips cycle 0x5f/0x63/0x62 chosen by `(n+1) % 3`, wait `Rand_Range(0.75, 1.25)` s between jabs, sets beacon class state to 5 (attacking) then 0 [C].
* attack_raptor: three phases by the threat's beacon state (0 idle, 2/3 approaching, 5 jabbing); jab clips 0x5f (frame > 0x5a ends), 0x63 (> 0x41), 0x62 (anim end); calls `fn@0x64d260(threat, v)` per jab with v = 0.35 / 0.45 / 0.55 (0x3eb33333, 0x3ee66666, 0x3f0ccccd) and 10.0 (0x41200000) in the idle phase [C values; the function's effect, probably a hit/knockback on the raptor, is L]; retreat clips 0x103/8 until frame 0x32.
* attack_scolo: if she still holds a javelin she drops it (`KAnn_exec_javelin_drop`), plays clip 0x109, and tracks the Scolo bone; speed floor 0.35 [C].
* attack_bat / grabbed_bigbat: clips 0x7d/0x7e/0x7f/0x80/0x82 selected by bat beacon state 0..3 (random 50 % between 0x7f/0x80 in state 0) [C].
* `KAnn_exec_action_interaction_attack_default@0x5fe8c0`, `..GEST`: dispatch.
