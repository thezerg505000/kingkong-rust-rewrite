# P08 Chapter scoring (formulas for P09-P12)
## Behaviour
Each scored chapter has a base score plus weighted lines. Bonus lines (kills) are multiplied by the chapter's bonus multiplier, penalty lines by its penalty multiplier. The total is clamped to >= 0. The best score per chapter is stored in the profile; the top 5 hiscore table starts at 20000/19000/17000/14000/10000.
## Code
- IntMIG_Page_ScoreNew@0x61a2c0, fn@0x4e1330 (compute), fn@0x4e1900 (draw line), fn@0x4dfdf0 (per-chapter row), fn@0x4e0dc0 (Kong test), fn@0x4e0b30 (sum of bests), fn@0x4e0ee0 (save best if higher) [C].
- Line score = ftol(|w| * mult * count); negative weight: mult = penalty mult and negated; positive: bonus mult. Header line (base, count 1) has no multiplier [C]. (_ftol arg recovered with objdump.)
- Kill_Credit@0x52f950 classes (P09), Stats_* counters (P10-P12).
