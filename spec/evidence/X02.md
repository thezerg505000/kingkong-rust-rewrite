# X02 Venatosaurus (main doc for X02 and CREATURE_AI A01-A03, A05-A11, A13, A15 as they apply to the raptor)

## Behaviour (what the game does)
`PNJ_Raptor_*` is ONE engine class that runs three species, selected by the species byte `this+0x20`:
`0xe` = Venatosaurus (this doc), `0x10` = Jack-level V-Rex (HP 2000, same states, different numbers), `0x16` = the small
herd compies ("galiminus"). Inside species 0xe the byte `this+0x24` is a variant: 0 standard, 1 standard with a
weaker bite class, 2 "alpha" (100 HP, scale 1.15, bigger bite, armoured against body shots).

The raptor idles at its territory for 1 s, then walks the territory's waypoint network (`VALA` = "va la", go there)
looking for prey. Prey = Jack, companions (any actor whose class code is 1..12), corpses (food) and shots/noise.
Targets are filed in a 20-slot "perceived actor" list with per-slot flag bits; a fixed priority chain
(`update_best_interest`) picks one. With a target it chases (`FIGHT`), loses sight and searches (`SEARCH`), hesitates
before committing to a new target (`HESITE`), bites when the target is within 3 m in a ~60 degree cone (`MORD`), and on
a bite that lands on Jack it grabs him (`GRAB`, see below) the first time (see grab counter) or else
retreats into a shark-style hit-and-circle mode for 3 s. Bullets cause one of three flinch reactions by damage size;
at HP 0 it falls, dies, lies 5 s and fades over 10 s. Corpses are eaten (`DEVORE`). Spears left in the body bleed it.

`+0x10` hp_max, `+0x14` hp, `+0x20` species, `+0x24` variant, `+0x34`/`+0x38` data overrides of hp_max / `+0x2194`

(flee / light / medium / heavy), `+0x1c3c` damage accumulator, `+0x2184` current speed, `+0x2188` anim-speed coefficient,
`+0x210c` vision range, `+0x3764/+0x3768` hesitation timer / duration.

## Perception (A03)
* Registry: every candidate actor is added by `fn@0x47e180(actor, extraFlags, ...)` (20 slots). Class code `+0x1620`
  from `fn@0x7dd2d0`: 1 = Jack, 2..12 = other humans/companions, 0xe = other raptor, 0x14, 0x1a, 0x21 = props/food.
  Life ratio 0 (or class 0x21 without flag) -> flag `0x400` (corpse/food). Interest value `+0x16c8` = `fn@0x6e44f0`
  (default 30.0 = 0x41f00000 when no data, player slots (`fn@0x418fb0`) or `+0x3d0 != 0`: 200.0 = 0x43480000) [C].
* Flag bits (`+0x1578[i]`) [bit: meaning, evidence]:
  `0x1` Jack is this slot [L]; `0x2` a shot passed near (check_shoot) [C set, L meaning]; `0x4` loud noise
  (check_sound adds when sound flag 0x2000) [L]; `0x8` inside the narrow view cone (check_vision) [C];
  `0x10` other raptor with an interest link [L]; `0x20` damaged by / heard hit from it (check_paf sets `0x20`,
  `0x21` if the source is Jack) [C]; `0x40` hit by a bullet-flag paf [C]; `0x80` another raptor already holds an
  interest on it (tag 0x10 scan `fn@0x6e4530`) [L]; `0x100` target at life ratio exactly 0.15 (downed) [C, species != 0x10];
  `0x200` target is in a hiding place -> ATTAQUE_CACHE [L]; `0x400` corpse / food [C];
  `0x800` heard noise [C]; `0x1000` human with a tag-0x48 link (being carried/occupied) [L]; `0x2000` target not
  reachable on the waypoint network (`fn@0x471c90`/`fn@0x47d050`) -> HESITE/VALA [C set, L meaning];
  `0x4000` claimed by another actor via tag 0x41 (e.g. already grabbed by another raptor) [L];
  `0x8000` forced by a cinematic (script msg 0x186a8/0x186ac) [C]; `0x1000000` seen with clear line of sight [C];
  `0x2000000` corpse too far from Jack (>50 m, 2500 sq) so ignored [C]; `0x4000000` just eaten [C].
* Sight (`check_vision`, once per frame): for every slot, tested with `Perception_ConeTest(headPos, forward, cos, range,
  target, near=1.0, flatten=1)` (the test is done in the horizontal plane):
  - seen iff horizontal distance <= near radius (1.0 m) OR (distance <= range+1.0 AND cos(angle) >= cosThr).
  - narrow cone: cosThr = 0.866 (`0x3f5db3d7`, 30 degree half angle), range = `+0x210c` = 10.0 m for species 0xe
    (8.0 for the V-Rex) -> sets flag `0x8`. [C check_vision/fn@0x4855e0, init]
  - wide cone for class 1..12 targets (Jack/humans): cosThr = -0.653 (`0xbf275526`, 130.8 degree half angle = 262
    degree field of view), range = 100.0 m, PLUS a line-of-sight ray (`Perception_LineOfSight`, mask `0x80000001`) and
    a second occluder check (`fn@0x486060`) -> flag `0x1000000` and slot "changed" `+0x147c = 1`. [C]
  - slots whose classification family (`fn@0x6e5230`/10) is 4, or 2 with sub-type 1/2, are skipped for species != 0x10
    (not prey) [C skip, L meaning].
* Hearing: `check_sound` loops sound events (`fn@0x43b780(2,..)`): if distance(listener, event) < the event's own
  radius (`Life_GetMax` of the event) -> `fn@0x47e180(src, 0x800 [| 4])`. [C]. `check_shoot`: for each shot message
  (type 0x15) and each live projectile in `Univers+0x1d98[32]` of kind 1, if the closest point of the shot line in front of the raptor
  is within **sqrt(25) = 5 m** (T-Rex 8 m, compy 4 m; the constants 25/64/16 are SQUARED, the old spec read them as metres) -> flag `0x2`, store
  time `+0x3760`. [C]
* Time memory: `+0x1458` = last time a `0x20` slot was updated; the interest handle carries a "last confirmed sighting"
  time (`fn@0x6e4570`); `age = Time_Now - sighting`.
* Wounded flag: `reflex`: hp/hp_max < 0.3 and no territory error -> `+0x1a5c = 1` (changes gait choice). [C reflex line ~435]

## Target selection (A05, `update_best_interest@0x863360`, `Raptor_SetBestInterest@0x47d6a0`)
Runs once per frame (latch `+0x1430`), only when not scripted (`+0x2110`). First match wins, else keep current:
1. a slot with `0x8000` (cinematic-forced) [C];
2. hiding-place handling (current target has `0x200`, state not in {7 MORD, 8 GRAB, 0x12 COODBOOL}): the loop that should choose among `0x4600`-free slots lost its assignment in the decompile, so the result is [L] (keeps the current target);
3. Jack (`+0x1468`) if flag `0x1` is set (and, V-Rex only, not already eating) [C];
4. a slot with `0x20` (something that just hurt it) if the last target change was > 4.0 s ago [C] (and state not 7/8/0x12);
5. if 10.0 s have passed since the last bullet hit (`+0x1c48`, stamped by check_paf for `f & 0x40`) and the current target is not another raptor: nearest slot with `0x10` (other raptor) in the same territory (`+0x1524[i] == +0x8f4`) [L meaning, C conditions];
6. nearest corpse (`0x400`, not `0x2000000`, and the corpse within sqrt(2500)=50 m of Jack) unless wait timer or state in {4 VALA, 7, 8, 0x12} [C];
7. nearest slot that is in the narrow cone (`0x8`), not (`0x80|0x100|0x400|0x1000|0x4000`), flagged changed, with a
   Jack/human preference: a Jack slot (class 1) always replaces a non-Jack current target; a different target of the
   same kind only if more interesting [L];
8. the actor that attacked it last (`+0x20f4` handle) if its slot flags & 0x4100 == 0 -> sets "force flee" `+0x20f0` [L];
9. in state 10 (DEVORE) on a carcass: a slot with `0x2`, then `0x4` (noise) [C];
10. a slot with `0x80` after 10 frames without a target (species 0xe only) [C].
When a target is (re)acquired: `+0x3764 = 0` (hesitation clock), `+0x3768 = rand(0.5,1.0) * [+0x3d8]` (hesitation length),
`+0x1458 = now`, `+0x1440 = 1` ("new target": ATTENTE/FIGHT go to HESITE), and `Interest_Create` (`fn@0x6e4270`, key
0x56b5e621, interest value from `+0x16c8`). `exec_check_requin`: while the Jack-chase wait timers are active nothing is re-picked.
Choosing between Jack / companions: no explicit companion preference exists in code; companions (class 2..12) are
ordinary slots, Jack gets rule 3 (and interest value 200 vs 30). Corpses are rule 6 and enter DEVORE
(ATTENTE/FIGHT: flag `0x400` and `+0x14d0 != 0`).

## State machine
Every state calls (in this order) `check_msg`, `check_vision`, `check_sound`, `check_collision` (empty stub, returns 0),
`check_paf`; any of them can return a non-zero (state-change) code that is returned immediately. Then the common
hit-reaction gate (H):
`+0x1c24` -> PAF_FLY; `+0x1c1c` -> PAF_FALL; `+0x1c10 || +0x1c18 || hp == 0` -> PAF_SLIDE. [C ATTENTE/VALA/FIGHT/MORD/HESITE/DEVORE/GRAB/...]
(GRAB/MORD/FIGHT apply H before anything else; the three flags are raised by check_paf below.)

## Hit reception (A10; `check_paf@0x849910`, damage taken from each weapon)
For each paf message (`fn@0x43bd70(4,..)`): `d = fn@0x51f110` (integer damage carried by the message = the weapon's
distance-band damage from `fn@0x53a370`, see `kk_mechanics::weapons`), `f = fn@0x51f190` (hit flags), `bone = fn@0x6e4170`.
Skipped if the source is `PNJ_Bontosaure_Patte` and the state is not one of 3,0xe,0xf,0x10,0x13.
* `f & 0x200` -> `CapLife(0)` (kill); `f & 0x100` -> `CapLife(0.15 * hp_max)`; `f & 0x80` -> `CapLife(0.3 * hp_max)`. [C]
* Damage applied: `Raptor_ApplyDamage(mult * d)` (not for PNJ_Scolo). `mult = 1`; only for `f & 0x440`: variant 0/1:
  `mult = 2` if bone id is 0 or 0xf5 (head/jaw bone) ; variant 2: if bone is not 0 / 0xf5, `d -= 5` (floor 0) [C].
* Flags `f & 0x800` subtract `d` from the fire gauge `+0x2194` (20.0 for 0xe; BURN/MORT use it).
* `f & 0x40`: time stamp `+0x1c48` (recent bullet).
* Accumulator `+0x1c3c += d`; `+0x1c44 += d`.
* Reaction class thresholds (variant 0/1 | variant 2): `T_light = 8 | 15`, `T_med = 11 | 20`, `T_heavy = 20 | 40`,
  `T_acc = 10 | 30`, `T_accsum = 10 | 30` [C check_paf]:
  - if source is Jack and the bite-leg latch `+0x1d54 != 0`: medium (FALL).
  - else if `d < T_heavy` or hit-direction z <= -0.5 or `f & 0x400`: if `d < T_med`: if `d >= T_light` or (not leaping and
    `acc >= T_acc`) or the source belongs to the raptor's own link: **light** (PAF_SLIDE), `acc = 0`; else (`T_med <= d < T_heavy`): **medium** (PAF_FALL), `acc = 0`.
  - else (`d >= T_heavy`): **heavy** (PAF_FLY), `acc = 0`.
  - `f & 0x200000`: light.
  - If the current anim is a long action (0x33/0x35/0x38..0x3b: leap) any reaction becomes heavy.
* Consequences: raptor flinches at every Colt hit within 5 m (8), every 3rd Colt hit at 5-25 m (acc 4+4+4 >= 10), every 5th Tommy hit (2*5), medium-falls to a
  Javelin (11), Sniper (10-15: 15 falls, 10 needs acc), flies from Shotgun pellets at <5 m (20) and Grenade (25).
* `+0x14d0 == 0` slot (no network reach) hit by the player accumulates `+0x1fac` (30/10 -> flag `+0x1fa0` forced walk).
* Javelin bleed (`exec_check_javelin@0x869370`): per spear embedded (max 3) and while hp > 2.0: `hp = max(2.0, hp - dt/60 * hp_max)` per frame, ie `hp_max/60` per second per spear [C]; spears also set the spear's state to 1.0.

## Attack (A07/A08, `test_bite@0x866ed0`, `exec_bite@0x84cae0`)
* Start (`test_bite`) needs: target index valid, not hiding/changed flags (`0x4400` clear), no flee/hit flags, and the
  target actor at Jack's bone / actor bone 0 (class 14 other raptor: bone 0 or 0x13 by facing). Species 0xe: horizontal
  d^2 < (3.0 * scale)^2 (= 9 m^2 for scale 1) and |dz| in (-2.0, 3.5), target in front (dot > 0); if d^2 < 2.0 bite at once; else bite if
  cos(angle to target) > 0.5 (60 degree half-angle). Then `GOTO(MORD)`. V-Rex: d^2 < 100, cone 0.342 (70 deg), reach 8/6/7 m by state. [C]
* Hit test (`exec_bite`, while the bite is armed `+0x1d2c`): cone test from the head bone (`+0x19a4`): cos >= 0.866 (30 deg), reach **2.5 m** (species 0xe; V-Rex 3.8/2.5, cos 0.766) against the target's capsule; success -> `+0x1d34 = 1` (once per bite), bite sound 7.
* On success, and only when the bite did NOT turn into a grab (and the target class is not 0x1a), the damage message `Msg_SendPaf(flags, self, 1e-4, target, damage, forward)`:
  variant 0 flags `0x4004` damage **6**, variant 1 `0x4002` damage 6, variant 2 `0x4004` damage **10** (V-Rex `0x4104` 1000, compy `0x1000` 1). On Jack the
  flags map to the wound classes of `H_exec_ch_Stimulus_Paf`: bit 4 = heavy, bit 2 = medium (`kk_mechanics::wounds::HitKind`).
* Grab vs bite: when the target is Jack and the raptor is not scripted: the bite becomes a **grab** (`fn@0x7dd8e0`
  grab link, GOTO GRAB) only while the per-raptor counter `+0x1d64` is 0; each successful grab of Jack sets
  `+0x1d64 = (+0x1d64 + 1) % 3` (`fn@0x41ea90` = modulo). Nothing else in `PNJ_Raptor_*` ever writes the counter
  (only `exec_bite@0x84cae0` lines 305/327 touch it), so as decompiled it goes 0 -> 1 on the first grab and then
  stays 1: **a given raptor grabs Jack once per spawn; later bites on Jack are plain damage bites** [C code,
  L that no other module resets it]. Companions (class 3..12): no grab if the last grab on a companion
  (`Univers+0x1e30`) is younger than `+0x3d4` s. Class 1/2 targets other than Jack are not counted.
* After the bite lands (not grabbed): `A09` wait timers.

## Recovery (A09) / shark mode
`ETAT_MORD` exit, all `PAF_*` exits and `check_requin` set `+0x1aa4 = +0x1aac = max(.,3.0)` (compies 0.5): while
`+0x1aa4 != 0` the raptor is in "requin" mode: ATTENTE/FIGHT send it to FIGHT circle mode (path mode 3, ring 5.0 m around the target, speed table index `+0x2118`), no new bite until the timer (decremented in
`exec_select_action`: `min(timer, dt)`) hits 0. `check_requin` also arms 3.0 s when the target is hidden/just lost (variant 0: 8.0 s `f_force_requin_mode_duration` limit when variant 0/2, 3.0 when variant 1).

## Pack behaviour (A15)
No explicit pack leader. Each raptor files an Interest handle on its target; others see it as slot flag `0x80`
(`fn@0x6e4530` scan of tag-0x10 interests) and `0x4000` (tag 0x41 claim, set by a grab) and exclude such slots from
the candidate loop (mask `0x5580`), so with several targets raptors spread over different targets; with only Jack
in range all raptors target Jack (rule 3). The compy herds (species 0x16) do share perception arrays across a
herd (`fn@0x4855e0/fn@0x485bf0`, up to 5 herds, "5 Troupeaux de galiminus, c'est trop"), raptors do not.

## Death (A11)
hp == 0 (set by `ApplyDamage` or `CapLife(0)`): flag-driven PAF_* (or directly A_TERRE if standing) -> A_TERRE (anim 0x1f) -> MORT (6; hp = 0, sound 2, `fn@0x47ec90(0.7)`), anims 0x30 / 0x11 by fire gauge,
-> after 5.0 s FADE (17) -> corpse released after 10.0 s (`fn@0x6112b0(..., 5.0, ...)` fade request).
The corpse is a food object (flag 0x400, other raptors: DEVORE).

## Bait (A13)
Raptor reacts to food only as `0x400` corpse/food slots (rule 6 above; class code 0x21 / flagged objects, with
`OBJ_Cadavre` checks in rule 9). There is no separate "bait" item logic in `PNJ_Raptor_*`; thrown bait must be an
actor of class 0x21 or a corpse registered through `fn@0x47e180`. Time budget: eating runs while the corpse exists, give up after 3.0 s without food (`+0x2410`).

## Gaps
* Gait speeds are data-driven (not in code); `step` takes them as a `RaptorInput` field (default from `gameplay_spec`
  rex_catalog roots, [G]).
* Many flag bit meanings are inferred from the setters (marked [L]); `update_best_interest` lost several assignments in
  the decompile (`local_c0 = i` in empty-looking branches), so rule order is exact but the "nearest" tie-breaks are [L].
* `GRAB`/`LANCE` hold timings are read from thresholds only; the Jack side (`H_ETAT_IA_grabraptor@0x5b0d50`) is a separate mechanic.
* `way_*` pathing, IK/neck and the cutscene states are only summarised.
* PS2 build: frame timing / difficulty (`Univers+0x4dc8`) may change waits; not checked.
