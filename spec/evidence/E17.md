# E17 Environmental ambush
## Behaviour
Fire and falling objects kill enemies through the same paf pipeline: grid fire pafs creatures (1000 damage, E04); burning/falling physics props (`ode_*`) forward pafs with strength to neighbours (`ode_exec_gestion_paf_externes`, flag 0x100000) and fire pafs (0x200000, E01); the Kong-level "rain of spears" is a scripted volley (`KPluieDeLances_*@0x74dc50`, `PluieDeLances_*@0x7d05b0`: wait state, then attack state that builds a target list `exec_construit_liste_cibles` and drops spears over time `exec_init_temps`, with a custom auto-paf `exec_gere_custom_auto_paf` so it does not hurt its own side). Quicksand (`Trap_QS_*@0x6ee5f0`) is a ground trap that pulls up to 5 clients (lerp speed `dt*6`) and blocks the area with a tag while active. Jack-side ambushes are level scripts using these.
