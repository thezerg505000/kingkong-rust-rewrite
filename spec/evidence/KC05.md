# KC05 Downward knockout
Main document: `spec/evidence/KC01.md`.

## Behaviour (what the game does)
The attack button during/after the repel (and not carrying) plays anim 0x1f (phase 5, `fn@0x884de0`). The blow is class
**9** (1|8; 10 = 2|8 in fury), damage 10 (20). Class bit 8 is the "knock-out" flag: the V-Rex's hurt rule lets a wounded rex
take damage only from hits carrying 0x2, 0x8 or 0x40, so the downward strike (and fury / heavy hits) is what hurts a wounded
rex; a Kong-level raptor hit by class 8 has its life set to 0 outright (`KR_exec_check_paf`: `Life := 0`). The strike shakes the
camera (amplitude 0.05, once, when the animation passes frame 0x20, flag `Kong+0xdf8`) and a successful hit also gives the
landed-hit camera shake (0.05 for class 8). After it, attack restarts the chain at punch 1.

## Code
`fn@0x884de0@0x884de0` (phase 5), `k_ETAT_main` phase 5 handler (0x89bd5d..0x89c1a9, shake at 0x89c162..0x89c197),

`k_exec_melee_hit` (class |= 8 when the current anim is 0x1f), `KR_exec_check_paf` (flag 8 -> `Life = 0`), `KT_exec_check_paf`.
