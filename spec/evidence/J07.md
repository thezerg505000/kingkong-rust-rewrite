# J07 Weapon-ready movement
Main doc `J01.md`. Holding the ready/aim buttons (pad buttons 4 or 6) with a weapon equipped clears the run flag (+0xba8) in
`H_exec_read_joy@0x579f30` (also requires +0xed2 == 0); Jack then walks at L*2.5 after a 0.1 s ramp (4.5 -> 2.5, stick-independent)
[C]. The aim flag (+0xb94, set while button 4 is held, or toggled by button 10 with button 6) forces the target speed to 0.5 [C] (an
assignment, so it applies even with a tiny stick). Hit reaction (`H_ETAT_IA_paf`, state 700) clears aim (+0x2e5/+0x2e6) [C].
Weapon swap (button 3) opens a 0.5-0.6 s window in which run speed is used [C values, L meaning].
Rust: `MoveState` (ready ramp), tests `ready_ramp_runs_4_5_to_2_5_in_a_tenth_of_a_second`, `target_speed_table`.
Gaps: pad button index -> physical button mapping not resolved (4/6 = shoulder triggers L). Per-weapon animation ids (local_50) not tabulated.
