# P15 Options (see C08/C09)
## Behaviour
Interface options are 0/1 Univers variables edited by IntMIG_Page_OptStart_Interface@0x638b30, saved in the profile.
## Code
IntMIG_Page_OptStart_Interface edits G+0x4db0, G+0x4de0, G+0x4de4, G+0x4d90; toggling 0x4de4 also sets 0x4de0 to the same value. Defaults in fn@0x4de6d0 (new profile): 0x4d90=1, 0x4d9c=2 or 3, 0x4da0=0, 0x4da4=0, 0x4da8=-1, 0x4db0=0, 0x4db4=1, 0x4dd8..0x4de4=0, 0x4910/14/18/0c=1.0, 0x4904|=1, 0x48fc=0x40 [C].
