# A11 Death (raptor view; one species)
Main doc: `spec/evidence/X02.md`. The engine class `PNJ_Raptor_*` serves species 0xe (raptor), 0x10 (Jack-level V-Rex), 0x16 (compies); this is how the **raptor** (0xe) does it.

## Behaviour (what the game does)
hp 50 (alpha 100). At hp 0: reaction state -> A_TERRE -> MORT (6) -> 5.0 s -> FADE (17) -> released 10.0 s later. Corpse = food for other raptors (flag 0x400). Spears bleed the raptor (hp_max/60 per second each, max 3, floor 2 hp so spears alone never kill).
