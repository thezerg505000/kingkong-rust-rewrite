# H11 Environmental damage (fire etc.)
## Behaviour
Fire is a set of "fire zone" messages in queue 0x17 (sphere type 0 with radius field 2, or segment/capsule type 1 with endpoints field 1 and radius field 2), created by `it_loop_on@0x4cd8d0` (fire props, via `fn@0x6e3080/3140`), `Projectile_Reflex@0x6d2990`, `Javelin_GFX_fire1@0x87fa70`, `fn@0x4d5b60` and Jack's own weapon callback `H_callback_after_blend@0x596090` (`fn@0x6e2fb0`). `Fire_PointInFireZone@0x6e3210(x,y,z)` returns 1 when the point is inside any zone (squared distance < radius^2). Callers: `H_callback_after_blend`, `Javelin_waittaken`, `it_loop_off`, `Xenon_Activate_Light_check`. The damage Jack takes inside a fire zone is applied in `H_callback_after_blend` (size 42427), whose decompile FAILED in the KB (timeout), so the number cannot be read statically. Other hazards: H09.md (deadly volume), self-push hit flags 0x42.
