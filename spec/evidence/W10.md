# W10 Scripted environmental events
## Behaviour
Collapses, obstructions and destruction for story progression are triggers acting on the objects above: `Trig*` actions (`TrigExec_*`, 167 trigger functions) switch objects, start fires (`TrigExec_Burn`), set fire parameters (`TrigExec_BurnParams`), register ignitors (`TrigExec_BurnCapa0`), enable water (`TrigExec_WaterEnable`); tests read the state back (`TrigTest_PositionGrilleEnflam`, `TrigTest_MultiGaoActive`, E18). Persistence across checkpoints is built into the objects: barricades, fires, torches and ODE structures store a "destroyed/lit" flag in the level save table (`fn@0x440500(self,k,0xc9,0x5dc)` id, `fn@0x432f10(G+0xc08,id)` test, `fn@0x432d50/00432de0` set/clear), so a reload restores the post-event world (`SGF_CP`, `IOB_Etat_Init`, `ode_state_init`, `it_init`). Camera shake / screen effects on collapse: `Msg_SendJackScreenFx` (IOB), `SFX_RumbleCam_Capa`.

## Numbers
Save-table record: key (0xc9, 0x5dc), id > 0 ; ids >= 15000 mean inverted sense in `ode_state_init` / `SFX_NET_Fire_ETAT_Init` (`id-15000`, result `1 - flag`) [C].
