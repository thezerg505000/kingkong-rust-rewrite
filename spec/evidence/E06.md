# E06 Fire sources
## Behaviour
Torches/braziers are `it_*` objects (`interactive_torche@0x4cd540` registers 6 key/state handles; `it_init@0x4cd5c0`, `it_loop_off@0x4ce740`, `it_loop_on@0x4cd8d0`, `it_callback_afterblend@0x4cee10`). A torch is on or off (`this[0]`); at init object flag 4 forces off, else flag 2 forces on; then two saved-flag ids (`this+0x1bc/0x1c0` from `fn@0x440500(self,0|1,0xc9,0x5dc)`): the first records that the torch was initialised once, and when it was, the second decides lit/unlit on reload; `it_loop_off` resets the second flag [C]. Off torches are lit by a fire zone containing the torch point (`Fire_PointInFireZone`), by a burning grid cell at a random offset within one cell, or by a level flag; once lit they stay on (and persist). `Xenon_Activate_Light_*@0x6d66f0` does the same for lamp lights ("Xenon lights"). `SFX_NET_Fire` can create a fire zone at the held spear tip (E01), which is how Jack lights his spear/torch (held items 6, 7, 8).
## Code
`it_init`, `it_loop_off` (above), `it_loop_on` (flame FX and light; not decoded in detail), `Xenon_Activate_Light_check@0x6d6730`, `Fire_PointInFireZone@0x6e3210`.
## Numbers
Default flame radius 0.2 (`0x3e4ccccd`), second radius = first, scale 1.0 (`it_init`) [C]; zone radius 0.5 [C].
## Data
Torch parameters per instance; saved-flag ids.
## Rust
`environment::{torch_lights, TORCH_DEFAULT_RADIUS, TORCH_DEFAULT_SCALE, point_in_fire_zone}`. Tests `torch_light_rule`, `fire_zone_shapes`.
## Gaps
Torch extinguish rules (`it_loop_on` ends only with the flag/level state), burn duration of a torch not found (no timer seen) [L].
