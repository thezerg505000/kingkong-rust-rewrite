# S05 Spear throwing
## Behaviour (what the game does)
Jack throws the held throwable (weapon id 6/7/8, also 5 grenade, 9, 10) from the throw state `H_ETAT_IA_lance`. The projectile is a separate
`Javelin` object (type 0/1/2 = weapon 6/7/8) created at Jack's hand and launched by message 2000 with a velocity, a gravity vector and a scale.
Direction = from the spawn point to an aim point 20 m in front of the camera; speed = 2.5 x 20 = 50 m/s. There is no loft compensation: gravity
-10 m/s^2 (z) bends the path. The flight tick (`Javelin_launch`) sweeps a ray from last position to current position and decides stick / glance / water.
