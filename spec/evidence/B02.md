# B02 Kong versus V-Rex
Static recovery of the Kong-level V-Rex state machine (`KT_*`, "Kong-vs-T-Rex"). Everything is read
from the decompiled AI2C functions of `KingKong8.exe` (PC). Tags: `[C]` read from code, `[L]`
inferred, `[G]` guess. KT offsets are written `Rex+0xNNN`; the KT model is **not** decoded in
`ova/models.json` (the m331 file only coincides on a few low offsets and must not be used for KT),
so variables are named by use `[L]`.

## Behaviour (what the game does)
The V-Rex (`PNJ_KTREX@0x4983b0`, one AI instance per rex in the Kong levels) fights two actors:
Kong (`Rex+0x5f8`, from `Univers+0x1c98`) and Ann (`Rex+0x5fc`, `Univers+0x1ca0`). It idles in
`attente`, picks a target (`KT_exec_fight_actor_select`) and goes to `fight_KONG` or `fight_ANN`.
Against Kong it swings (distance <= 8), lunges with the jaws (5.5..14) or charges; Kong's blows
cost it life from a gauge. Light hits make it flinch (`paf`); three light hits within 2 s (or two
heavy within 2.5 s) make it counter-attack. At life 0 it is **knocked down** (`KO_au_sol`, 5 s on
the ground, then it gets back up with at least 20 life). While it lies there, wounded, Kong may
start the **jaw-break finisher** (`KT_ETAT_Finish`, a mashing tug-of-war) which ends in `mort`.
Kong can also grab it (`grabbed`) for hits, slams and a throw (`projectile`, 20 damage on impact).
A rex flung or charging into a wall also takes 20.

**State machine mechanics [C].** Each `KT_ETAT_x` stores its id in `Rex+0x3a8` (previous in
`+0x3ac`, state timer `+0x3b4 += dt` (`DAT_012f797c`), exit flag `+0x3b0`, "return state" `+0x3b8`).
`GOTO(x)` in this document is the compiler pattern `if (fn@0x43f6e0()==2) {fn@0x43f720(x); return 5;}
else {fn@0x43f2c0(2,x); return 0;}` - the first `GOTO` executed in a frame wins, so the order of
the tests below is the priority order. The state "pointers" are resolved in `PNJ_KTREX` by key
(`fn@0x402080(key)`; keys are the AI2C table keys, e.g. 0x330025ac = `KT_ETAT_fight_KONG`).

**State ids [C]** (`Rex+0x3a8`): attente 0x00, charge 0x04, paf 0x0b, KO_au_sol 0x0c, projectile 0x14,
chute 0x15, mort 0x16, JumpAttak 0x17, attaque 0x18, derap 0x1a, cri 0x1b, fight_KONG 0x1c,
fight_ANN 0x1d, fight_cible_hauteur 0x1e, grabbed 0x65, choppe 0x6a, Finish 0x6c, I_Finish 0x6d,
TEST 0x29a (debug, unused).

### Life gauge and how Kong's damage is applied
* The "Life" variable (`Rex+0x880`, AI type 0x1e, built in `KT_TRACK_init` by `fn@0x770900`) is a
  vector slot (max, current, wound ratio). `fn@0x7dd290` = current, `fn@0x6e43f0` = max,
  `fn@0x6e44f0` = ratio; `fn@0x770b70` = **wounded** when `cur/max <= ratio` (debug strings
  "Normal"/"Blesse"/"Gladiator" in `fn@0x770d10`) [C]. `fn@0x770af0(life,d)`: `cur = max(cur-d,0)`;
  `fn@0x770aa0(life,v)`: `cur = v` [C].
* Initial values are instance data (`Rex+0xf4` max, `+0xf8`/`+0xfc` start/ratio inputs, `+0x100`
  mode 0/1/2 = start normal / start wounded / start at 0). **Not recoverable from the exe** [gap].
* `KT_exec_check_paf` (0x49e580) loops over the hit list (type 4 stimuli) each frame. For each hit
  with flag word `f = fn@0x51f190(hit)`, damage `fn@0x51f110(hit)`:
  * `Rex+0x2d0 |= f` (accumulated flags); hits with `f == 0x800` are ignored; hits that arrive
    while a held-grab message of kinds 0x14-0x18/0x1e-0x22 is active are ignored.
  * **Damage applies if `(f & 0x10) == 0` and (`!wounded` or `(Rex+0x2d0 & 0x4a) != 0`)** [C]:
    a wounded rex only takes damage from hits carrying 0x2, 0x8 or 0x40.
  * If the hit comes from Kong: `Rex+0x288 = 0; Rex+0x28c += 1` for `f & 0x10 == 0`, else
    `Rex+0x294 = 0; Rex+0x290 += 1` (light / heavy counters, see paf).
    `fn@0x559f20(f)` ("knock-down capable": life != 0, `f & 0x10 == 0`, and (Kong in fury or
    (state != JumpAttak and `f & 2`))) calls `fn@0x606dd0(kong,0)` (Kong's hit-connected feedback) [C].
  * the hit with the biggest damage becomes `Rex+0x2a4` (attacker) and the rex goes to `paf`.
* Fixed damages: **20.0** (`fn@0x770af0(life, 0x41a00000)`) when a thrown rex lands (grabbed
  throw, projectile impact), when the charge hits an obstacle (`fn@0x555550`), and in derap [C].
* `KT_TRACK_reflex` (every frame, before the state): if life <= 0 and (state is 0x1c/0x1d/0x1e or
  0) -> `Rex+0x2e0 = 5.0; Rex+0x2ac.. = -forward; GOTO(KO_au_sol)` [C].

### Reflex (pre-emption) order [C KT_TRACK_reflex@0x49a430]
1. `KT_exec_check_fury`: a kind-2 stimulus (Kong's fury shout) within 30.0 -> `Rex+0x21c`;
   if state is fight_* / attente / attaque -> `Rex+0x220 = source; Rex+0xad0 |= 0x20; GOTO(cri)`.
   (`KT_ETAT_charge` also aborts: `"Kong passe en furie => stoppe charge"`.)
2. state attente/fight_KONG and `fn@0x556470` (target is Kong and Kong's global mode `Univers+0x6264 == 10`, or a queued
   interaction result; read as "target is up high" [L]) -> `GOTO(fight_cible_hauteur)`.
3. `KT_exec_check_msg`: msg 4 and state != JumpAttak -> `JumpAttak`; msg 1 from an actor >= 50.0
   away and `fn@0x556cb0` -> `choppe`; `Rex+0x38c` (charge target, from msg 9 or fight_KONG) -> `charge`.
4. life <= 0 -> `KO_au_sol` (above). 5. `Rex+0x270` (forced-Kong flag) -> `fight_KONG`.
Timers aged here: light-hit age (`+0x288`) clears the light counter at > 2.0 s, heavy age
(`+0x294`) clears the heavy counter at > 2.5 s [C].

## Gaps
* Rex life numbers, speeds and Kong-attack damage values are level/instance data (not in the exe).
* The meaning of several helper predicates is `[L]`: `fn@0x603f00(kong,0x10)` ("in finish"),
  `fn@0x556470` (Kong carrying something), `fn@0x559db0` (charge cool-down), `Rex+0x114`.
* The Kong -> rex grab message protocol (kinds 1..0x23) is only partly mapped (see list above).
* `KT_ETAT_Finish` fail rule: the original tests `cursor < 102` every frame after 2.74 s; an idle
  Kong makes the cursor regress under the resistance and the rex escapes (verified in a test,
  but the animation frame rate is unknown, so wall-clock times are `[G]`).
* PS2 build: untested; timers are in seconds via `dt` here, the PS2 build may clamp dt differently.
* `X04` Jack-level V-Rex (`PNJ_Tyranosaure_Jack`) is a different machine and is not covered.

## Fight simulation (`kong::fight` + `kong::ai`, added 2026-10-08)
A pure-Rust two-body Kong-versus-rex fight, `Fight::step(dt, KongInput) -> Vec<FightEvent>`, and a Kong
"brain" (`KongBrain::think(&Fight, dt) -> KongInput`) that plays it. Both are deterministic (fixed 1/60 s tick,
seeded xorshift) and engine free; the Bevy slice only has to render the events and feed a pad.

### Recovered (`[C]`/`[L]`, reused from the existing ports, not re-derived)
* Kong's combat-phase machine and latched inputs: `combat::next_phase`, `ready_for_input`, `phase_params`, `recovery_anim`,
  `punch_variant`; the blow table `combat::blow` (10 / 20 in fury, classes 1, 2, 9, 10, 0x14, 2 for the counter lunge,
  grab strike 10 class 9 at frame 0x12); invulnerable anims 6, 7, 0x16 (`is_invulnerable`); side-step gate dist^2 <= 196 and
  dot >= -0.342 (otherwise the non-invulnerable roll); chain frame 0x37; light hit-stun punch cancel after frame 0xf;
  `hit_reaction` for Kong's flinch; camera shake amplitudes by class.
* Fury: start only by the pound pattern (special -> repel, special during the repel -> chest pound 0xab, special held past
  frame 0x82 with no other button -> roar 0xad, `fury::PoundWindow`), 18.0 s, +1.5 per landed blow (once per action) capped at
  15.0, -2.5/-5.0 when hit while > 5.0, anim speed 1.25, damage 20 / class 2, timer paused in grab-mash actions, life 0 in
  fury -> 10.0, last stand 10.0 s (a hit under 5.0 s kills, above cuts it to 5.0). Shout reaches a rex within 30.
* Rex: the whole `KtMachine` (priority-ordered transitions, KO 5.0 s / hold 4.75 s / 20.0 life floor, counters 3 light in 2.0 s or
  2 heavy in 2.5 s past frame 19, charge distance 20/10 with facing cos 0.866, melee 8.0, bite 5.5..14.0, fury shout -> `cri`,
  pound -> `cri` instead of charging, 20.0 impact on wall/thrown), `hit_damage` (a wounded rex only takes 0x2/0x8/0x40 hits, so
  plain class-1 punches do 0 once it is wounded), `knockdown_capable`, attack packets (sweep 1/10, tail 2/10, jaw 2/10, charge
  0x42/10), grab/throw/slam end states (`grab_end_state`), rex hold timeout 1.0 s (5.0 s wounded) when Kong holds it and does nothing.
* Jaw-break finisher: offered only when the rex is `KoAuSol`, wounded, in its first knock-down (`Rex+0x4e8` window = not
  `knocked_down_before`) and Kong is within 22.0 (`finish_accepts`); 2.74 s lock then `FinishMash` (pull 3.5-0.5v per press, resist
  +2/s, -0.5 per press, escape if the cursor is under 102 after the lock, decay 20/s or 3/s in fury).
* Throw release frame 60, slam release frame 78 (`fn@0x889e10` callers), throw -> `projectile` -> 20.0 impact -> `derap` or KO.

### Ours (`[G]`, all marked in the source)
* Geometry and kinematics: arena radius 32 m, body radii (rex 4.0, Kong 1.0), Kong run 8 m/s, rex walk 4 m/s, charge 14 m/s,
  skid 10 m/s^2, throw 20 m at 25 m/s, shove 4 m, knock-back from the hit-stun strength, side-step 5 m / roll 6 m (the real
  locomotion is animation root motion), reach = rex surface within 3.0 (sweep, [C]) + 1.5, counter lunge 4.0 + 1.5.
* Animation bank data that is not in the exe: lengths, hit windows, cancel frames (`fight::anim_info`), rex attack
  durations and blow moments (sweep 1.4/0.55, tail 1.4/0.6, bite 1.8/0.7 s), cool-downs, Paf/Cri/Derap durations, finisher
  animation length (480 frames), Kong's pull phase `value` (a 0.4 s cycle), placeholder anim ids for walk/run, grab start,
  throw, slam and the finisher poses (the code references them through tables not decoded).
* Life numbers: rex 650 (wounded at 35 %), Kong 100 (wound ratio 35 %, last-stand restore 30 %). The real numbers are level
  data; 650 was chosen so a fight takes about one minute.
* Which rex states offer a grab to the attack button (`Derap`, `Cri`, the recovery tail of an attack, any KO): the conditions in
  `KT_exec_propose_grab` ("se propose", "DODGE", "bad axe") were not decoded. Grab moves: attack = grab strike (anim 0xa2),
  special = throw, jump/roll = ground slam, cancel = release. The "bite" the manual lists has no Kong-side function (KC08);
