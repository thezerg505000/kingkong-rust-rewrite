# N10 Companion injury (also the wound mechanics shared with Jack)
## Behaviour
The same stimulus function handles Jack and the companions; the branch is chosen by `this[0]` (0 = AI companion, !=0 = human Jack). Status is stored per slot in `G+0x1bb4+4*slot` (float): **0 healthy, 1 wounded, 2 recovering, 3 dead**. (The older `wounds.rs`/gameplay_spec labels "1 healthy / 2 wounded" are off by one: `H_TRACK_init` writes 0 at spawn, a hit on 0/2 writes 1, a hit on 1 writes 3.)
Companion rules (`H_exec_ch_Stimulus_Paf@0x5a3060`, `*this == 0`): hits from Jack are ignored unless `this[0x2a9]`; ignored while dead, while carried/carrying (states 0x262/0x2c5), with cheat bit 1 of `G+0xbf0`. A first hit while not "hurt" (`this+0xb8f <= 0.5`) only starts the hurt timer (heavy paf flag 4: 15.5 s, flag 2: 10.5 s, else 5.5 s; no difficulty scaling). A hit while the hurt timer is still running makes the companion wounded (status 1, wound time stored in `this+0xb93`, stats counter `fn@0x52f7b0`). A hit on a wounded companion kills it (status 3) only if the wound is at least 9.0 s old; younger wounds just refresh the hurt timer to 4.0 s (unless paf flag 0x100). Cheat bit 0x200 stops all status changes.
A wounded companion limps (`H_ETAT_IA_walkstunned` 0x264 / stunned state): Ann (slot 2) recovers by herself after 5.0 s stunned (`H_ETAT_IA_stunned`: status 0, `G+0x1c00+4*slot = 3`); any other slot becomes "recovering" (2) after 8.0 s stunned, and 30.0 s later healthy (`H_TRACK_Reflex`: `fn@0x43c690(this+0xf35, 30.0)`). Ann can heal a wounded teammate or Jack (state `H_ETAT_ann_heal` 0x3ee, order 2): approach, play the heal animation, status -> 0 after 5.0 s (2.0 s when the patient is Jack and not dead), `G+0x1c00+4*patient = 3`. Deep water/hazard (`fn@0x42b770(obj, 0x40)`) kills a companion after 2.0 s (Jack 1.0 s) [C].
## Code
`H_exec_ch_Stimulus_Paf@0x5a3060`; `H_ETAT_IA_stunned@0x5c6e20` (lines 140-210); `H_TRACK_Reflex@0x58de70` (lines 918-1160); `H_ETAT_ann_heal@0x5d0380` (line ~800-890); `H_exec_propose_heal@0x5d2080`: proposal when this slot is 2, the patient slot's status is neither 0 nor 3 (and for patient != Jack: not already at 3 / or Jack not dead...), within the heal window, path exists (`fn@0x53bb50`), timer 2.0 s [C].
Carry: `H_exec_propose_carry@0x5c7b50` (non-Ann AI, in cover/assist/shoot states, target stationary `speed <= 0.3` and `fn@0x68dd60(target)`), `H_ETAT_IA_carry@0x5b45b0` (0x262) and `H_ETAT_IA_carried@0x5c6700` (0x2c5): a wounded teammate can be carried; proposal weight x0.5 slot 3, x2 slot 5, x1 slot 6 [C].
