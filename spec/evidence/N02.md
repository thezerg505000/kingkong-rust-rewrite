# N02 Contextual dialogue
## Behaviour
Companion speech comes from three sources: (1) scripted lines (`TrigCINE_Speech`), (2) lines the companion's own states queue when something happens (`this+0x2814` = pending speech key, spoken by the speech service), (3) object-owned cues (the door cues of `InteractiveDoor_exec_speech`). All are requests to the speech manager `SPEECH_*` (`GST_SPEECH`, `SPEECH_TreatRequest@0x6f71e0`), which has **two simultaneous channels** (loop `local_c < 2`), subtitles ("display : ") and lip sync (`<lipsync>`) and plays the sound on the speaker object (or 2D when the speaker is the player's camera) [C].
## Code
- `TrigCINE_Speech@0x765960` (trigger action): speaker `param[1]`; line index `param[0x15]` selects the key pair at `actor+0x49ec+8*idx` (variant at `+0x49f4` when the speaker is farther than 8 m: `DistSq > 64`); sends message type 0x13 id 0x38d1b717 sub-code 0x186a3 via `fn@0x43b580`; the trigger completes when the speaker is the player (or mode 3), or when a speech channel (`G+0x16b0`) holds the speaker; it gives up waiting for the line to start after 3.0 s [C].
- `H_CINE_Speech@0x584300` (state 0x7d2): calls `fn@0x51ef50(speaker, 0, key..., 0.1, -1, 0...)`, turns the actor towards the addressed object when `dot > 0.6` (and the object is > 0.1 away), repeats the line every >1.0 s while the channel is silent, ends when the sound ends or after 15.0 s [C].
- `fn@0x51ef50@0x51ef50` (named here `SPEECH_Request`): packs (speaker, slot, sound id, priority 0.1 default, -1, flags 5/0/2) into message 0x38d1b717 type 0x13 [C].
- Situational lines: `H_ETAT_IA_psss` sets `this+0x2814` = per slot keys (slot 2: 0xd0005c2c / 0xd0005c31, slot 3: 0xd00053dc / 0xd00053e6 and 0xd00053d2 / 0xd00053d7, slot 5: 0xd0005c36 / 0xd0005c3b, default 0xd0005a8b / 0xd0005a90; the two values select by `this+0x112c`); `H_ETAT_IA_hide` 0xd00053af / 0xd000580d (only slot 3 Hayes, when profile stat `G+0x1df4+0x50*profile > 20` [stat meaning unknown], at most once per 30 s, event kinds 3/4/7), 0xd000583a (after 2.0 s without a cover, `fn@0x53a0f0` priority 0x5a); `H_ETAT_IA_help` 0xd00053f5 (Hayes assisting Jack under rush), 0xd000583f (target > 10 m away); `H_ETAT_ann_heal` 0xd0005162 / 0xd0005153 (starting a heal on a wounded teammate / Jack), 0xd0005158 (healed); `H_exec_propose_help` 0xd0005b0c ("no weapon to help with") [C]. `fn@0x53a0f0(category, key, priority, 0)` queues a line with a category cooldown (internal, not read).
- Door cues: `InteractiveDoor_exec_speech@0x877df0` (see E09.md/E11.md): per-cue 30 s cooldown, speaker = nearest active companion slot 2..6 within the door's radius, only when the door is within 10 m (`DistSq <= 100`) [C].
