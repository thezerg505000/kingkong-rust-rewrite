# AN02 Carry Ann
Main doc: `AN01.md` (all tables). This file lists what is specific to carrying.

## Behaviour
Once picked up Ann stays in `grabbed_KK` (state 2) for as long as Kong's hand query (`Kong+0x2b4`) is valid. Her pose follows Kong's hand actor (parent link mode 3) so her position is Kong's; her facing is slerped toward the direction Kong faces at 3 /s. She does not act, throw or navigate while held (the server slots `+0xe0..+0x114` are zeroed on entry and `KAnn_exec_serveur_get@0x5f70e0` only polls 14 message slots). She still takes hits (AN04). If a big bat grabs her while held (`Ann+0x144 != 0`), she switches to `grabbed_bat`.

## Code
`KAnn_ETAT_grabbed_KK@0x5f0bd0`: exits to `follow_network` (`DAT_b991ac`) when `Ann+0x12c == 0` (the Kong link is gone) or when the Kong query category (`fn@0x6e2e50(+0x8c)`) is 8 or 9 (released/thrown categories) [C]; to `paf` (`b991d0`) when `Ann+0x22c != 0`; to `grabbed_bat` (`b991c0`) when `+0x144 != 0`. Categories 1, 2, 10 re-set `+0x1098 = 1` each frame (busy) [C]; category 1 plays Ann clip 0x10 if `+0x54`, otherwise 0xfa [C].
Kong side per frame: `k_reflex@0x8a4360` l.326: `if (+0x318 != 0 && handle invalid) +0x318 = 0` (Ann lost) [C].

## Numbers
See AN01 table (blend 10 /s, facing 3 /s). Carry has no speed penalty in `k_ETAT_grab_ANN` itself; Kong's walk speed while carrying is in `k_ETAT_main` (movement owner) [gap].

## Gaps
Walk-speed/jump restrictions while carrying are not recovered here (see AN07).
