# X14 Brontosaurus (`pnjbronto_*`, `PNJ_Brontosaure`, organiser)
Status RESEARCHED.

## Behaviour
A herd of walking sauropods: `PNJ_Brontosaure@0x7ef2b0` / `PNJ_brontosaure_organizer@0x6eafc0` (`PNJBrontoOrg`) spawn and steer herd members; each member `pnjbronto_*` (16 functions `@0x7ef350-0x7fbbd8`, legs `pnjbrontopatte_*@0x56bc50/0x56bd50`) walks a waypoint path (`walk`, `wait`, `exec_move`, `computemovedest`, `computewpwidth` = lane width), keeps feet on the ground with IK (`exec_IK_legs` 14.5 KB, neck IK). Non-hostile: the damage is **trampling**: each foot checks the squared distance to Jack/Kong and sends a paf when a foot is within 3 m (`dist^2 < 9`). The herd stampede = the organiser raising speed (level script).
