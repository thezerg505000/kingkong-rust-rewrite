# P13 Unlockable extras (and P14 alternate ending)
## Behaviour
20 extras slots. Slot i unlocks when campaign progress >= f[i] and total best score >= threshold[i]; slots with f>9 unlock by an event flag set from a cheat code. Slot 2 (alternate finale) needs 250000 total and 100% progress, matching the manual.
## Code
fn@0x4dc1b0@0x4dc1b0 (Extras_ComputeUnlockMask) writes bitmask G+0x5684; inputs total best fn@0x4e0b30 (sum over 40 chapter bests, replay score overrides lower) and pct = ftol(G+0x4ffc/(G+0x5008-1)*100) (100 if at end). Event flags G+0x5e88+4i set by IntMIG_Page_CheatFinal@0x61c540. Display order fn@0x4dc0c0, new-unlock count fn@0x4dc660, launch IntMIG_Page_Xtra@0x629bf0 [C].
## Numbers
Score thresholds by slot: 0:75000, 2:250000, 6:20000, 7:50000, 10:100000, 11:150000; -100 (never via score: slots 13,14,16,17); -1 none. Progress f: 1:0.15, 2:1.0, 5:0.75, 8:1.0, 9:0.5, 12:0.05; event flag: 3 (f=20), 15 (f=10). Slots 4,18,19 always unlocked [C; slot 4 uninitialised, L].
Launch: slot 0 fn@0x4205e0(1); 2 chapter 2003 with G+0x567c=1; 3 fn@0x4205e0(3); 5,6,7,9,10,11,12,15 -> maps 0x32,0x33,0x38,0x39,0x34,0x35,0x36,0x37 (artwork galleries); 0x12 credits map 7; 0x13 fn@0x4205e0(4); slots 1 and 8 are video filters (bits 0x2,0x100).
## Data
Maps 50-57 `_artwork_*`; BONUS_0..7.BIK via fn@0xa700f0.
## Rust
`progression::unlock_mask`, `progress_pct`, `EXTRA_SCORE_THR`, `EXTRA_PROGRESS_THR`; test `unlocks`.
## Gaps
Names of extras per slot are [L]; cheat strings are hashes (not inverted).
