# C06 Zoom (FOV transitions)
## Behaviour (what the game does)
While Jack holds aim (+0xb94) the camera FOV eases from 1.2 to 0.6 (about 2x), or to 0.3 when the equipped weapon id is 4 (sniper-class, id meaning L). If Jack's flags +0x110c or
+0x1118 are set (some carried/grab state) the aim does not zoom (target stays 1.2). With a lock-on target and no aim the FOV target is computed from the target geometry. The current
FOV eases with k = 5*dt per frame in both directions (the 0.9*2*dt in the old notes was not found on this path).
## Code
`CM_Cam@0x45b1b0` 0x45f8c8-0x45fce5 (disassembly): aim -> 0x45f909 (1.2), 0x45f91b `G+0x3348 == 4` -> 0x45f94a (0.3 = 0x3e99999a) else 0x45f956 (0.6 = 0x3f19999a); not aiming and +0x58 == 0 -> 0x45fc43 (1.2);
`fov = target*k + (1-k)*fov`, `k = clamp(5*dt, 0, 1)` at 0x45fc6d (snap if +0x9c). Camera FOV lives at camera +0x1c. A separate cinematic branch (0x45c968/0x45c977) writes 1.2/0.6 to +0x1c for camera mode +0xb8/+0xc8.
