# A15 Group hunting (raptor view; one species)
Main doc: `spec/evidence/X02.md`. The engine class `PNJ_Raptor_*` serves species 0xe (raptor), 0x10 (Jack-level V-Rex), 0x16 (compies); this is how the **raptor** (0xe) does it.

## Behaviour (what the game does)
No leader. Each raptor holds an Interest on its own target; other raptors treat those targets as taken (flags 0x80 / 0x4000, excluded by mask 0x5580) so a group spreads over several targets and stacks on Jack when he is alone (rule 3 ignores the mask). Each landed bite arms every raptor separately; the global grab spacing `Univers+0x1e30` only limits grabs on companions. Compies (species 0x16) additionally share perception per herd.
