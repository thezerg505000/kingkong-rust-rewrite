# X03 Small V-Rex variant
Main docs: `X04.md` (Jack-level rex), `B02.md` (Kong-level rex). Status RESEARCHED (identification only).

## Behaviour
There is **no separate "small rex" class or species byte** in the exe. The candidates the code distinguishes are: the Jack-level rex (species 0x10 of `PNJ_Raptor`, scale 1.5, hp 2000, X04) and the Kong-level rex `PNJ_KTREX@0x4983b0` (`KT_*`), whose actor scale is set to 1.0 in `KT_TRACK_init@0x498640` and whose life gauge and wound threshold come from per-instance data (`Rex+0xf4` max, `+0xf8/+0xfc`, `+0x100` mode). The "smaller but still threatening, encountered separately from adults" rex is therefore a **level-data instance** (smaller scale, smaller life gauge, spawned separately, e.g. the three-rex level `10B Trois T-Rex`) [L]. Strings: `"10B Trois T-Rex"`, `"05C Kong vs first TRex"`, `"03E Chased by the trex"` (`uni_init` level names).

## Code
