# J03 Strafing
Same mechanism as forward: see `J01.md`. Strafing is the lateral component of the camera-relative stick vector
(`move_direction`, `GG_Exec_Joy@0x695030`); no separate strafe speed or animation switch exists in
`H_exec_select_action`. The direction vector is normalised but the speed term uses L = sqrt(x^2+y^2), which is not clamped to 1, so a full diagonal
stick (each axis 1.0) gives L = 1.414 and up to 6.4 run speed (1.41x a cardinal push) [C].
