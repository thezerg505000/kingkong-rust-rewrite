# E01 Flammable vegetation (main fire document: E01-E04, E06, E07, E17 share it)
## Behaviour
Vegetation is not an object: it is **ground**. The level has a two-layer ground grid; layer 1 holds one byte per cell, low nibble = ground material, high nibble = fire state. Material 8 is flammable (grass/brush). Fire is a script-started "grid fire" object (`SGF_*`, "spreading grid fire"): it ignites one start cell, then every `spread_interval` seconds ignites **one** more flammable, unburnt cell next to the oldest still-spreading cell, and burns each cell out after `burn_time` seconds, oldest first. A burnt cell (state 0x80) can never ignite again, so a burn is a one-shot barrier removal. While a cell burns, creatures standing on it get a 1000-damage fire "paf" (instant kill for the creatures that implement it); AI companions (`*this == 0`) get a "fire near me" flag when any burning cell is within +-2 cells (AUDIT: not Jack). The same grid byte lights torches. A second system, `SFX_NET_Fire`, runs a fire front along a waypoint network (fire lines/trails); a third, the `ode_*` physics objects, can catch fire from fire pafs (flag 0x200000), burn 10 s and pass fire to touching objects.
## Code
- `SGF_Init@0x6824d0`: if `this+0xec==0` and `this+0xbc==0`: registered ignitor objects (`TrigExec_BurnCapa0@0x78ae70` stores up to 10 objects in `Univers-like+0xc4+4i`) are moved to the fire and shown; `this+0xb4` (burn time) and `this+0xb8` (spread interval) are overridden by `X+0x16620` / `X+0x16624` when those are non-zero (`TrigExec_BurnParams@0x78aee0` writes them from the trigger's params +0x18/+0x1c); seed = own position, `tail=1`, start time stored in `this+0xd7c`; next state `DAT_00b997f8` (= `SGF_Propage`). If `this+0xbc!=0` it waits 0x78 (`fn@0x43fb20`) then goes to `DAT_00b997e0` ([L]: the checkpoint state `SGF_CP`).
- `SGF_Propage@0x6827c0` (per frame): (1) when `Time_Elapsed(this+0x10ac, this+0xb8)`: loop from the front index `this+0x109c`: front cell not burning (`(v&0xc0)==0`, only the seed) -> ignite it; else scan the 8 neighbours (dx -1..1 outer, dy -1..1 inner, +-1.0 world units) for the first with `!(v&0x40) && !(v&0x80) && (v&0xf)==8`, write it at `tail`, set its high nibble to 0x40 (`fn@0x427350(cell,0x40)` keeps the low nibble), add 0x20 on layer 0 (`fn@0x427410(cell,0x20)`), `tail=(tail+1)%200`, stop for this tick; if none, `front=(front+1)%200` and continue. (2) burn-out: if `this+0xb4!=0` and the oldest cell (`this+0x10a0`) has burnt `>= this+0xb4` s (`Time_Elapsed(this+0xd7c+4*oldest, this+0xb4)`): layer 0 -0x20 (`0xffffffe0`), high nibble := 0xc0 then 0x80 (burnt), `oldest=(oldest+1)%200`; when `oldest==tail` the fire object ends (state `DAT_00b997ec` = `SGF_Fin@0x682f20`, removes the two FX handles). (3) audio/light: every 0.15 s (`0x3e19999a`) pick a random live cell as FX position; the squared distance of the nearest of up to 10 cells per frame to the camera object (cutoff 1600 = 40 m) gives volume `1 - d^2/1600`, smoothed with `dt*20` (`SGF_sound@0x682fa0` consumes it).
- `SGF_CP@0x683070` (checkpoint/persistence): the level keeps a saved flag per fire (`fn@0x440500(self,0,0xc9,0x5dc)` id, `fn@0x432f10(G+0xc08,id)` test, `fn@0x432d50` set). If saved: flood fill (3x3 neighbourhood, same free-flammable test) from the object's own position into the ring and mark all reached cells 0x80 (burnt) so the burnt patch is back after a reload. If not saved and the own cell is already burning (`&0x40`), set the saved flag.
- `TrigExec_Burn@0x78af30` (level trigger action, E02/E05): if the grid exists, target cell = position of the trigger's object (`param+4`, else the running object); if it is not (material 8 and unburnt) try the 8 neighbours; if one qualifies, spawn an `SGF` object there (`fn@0x4120b0(DAT_00b99dc4,pos)`) and write its `+0xb4` = trigger `param+0x18` (burn time), `+0xbc` = 0. `TrigTest_PositionGrilleEnflam@0x46a360` is the matching test: true when the cell at `param+4`'s position has the burning bit (0x40) (gate for scripted progression).
- Creature reactions to a burning cell (`byte & 0x40` of the cell under the creature, only if the level fire flag `X+0x8938` is non-zero): `PNJ_Raptor_reflex@0x835ea0:302-325` (not for state 0x10): calls `fn@0x415950(obj,8,0)` (object flag 8), sets burning flag `+0x38e0=1.0`, and each frame sends `Msg_SendPaf(flags 0x200200, damage 1000, random xy +-0.5, z 1.0)`; `PNJ_Scorpion_reflex@0x4f8610:204-228`: burning flag `+0x182c=1.0`, timer `+0x1820` (reset to Rand(0.5,1.5)) then paf 1000/0x200200 and state change 0xc; `PNJ_Scolo_Reflex@0x81a710:334-360`: per body part, timer `+0x1ccc` reset Rand(0.3,0.5), paf 1000/0x200200 via `fn@0x6e3e70`; bats: `BC_reflex@0x72d400:1055` leads to `BC_ETAT_Brule@0x746590` (anim 0xe then 0x12/0x13/0x16, moves along `-forward*1.5`, steering lerp `dt*5`); `PNJ_EatMe_Reflex@0x521fb0:137` sets its own burning flag (`this[299]`) and counts a timer against 5.0 s [L meaning]; `fn@0x6c6750@0x6c6750` (bat vision/path test) treats burning cells as blocked.
- `ode_exec_gestion_feu@0x6a3740`, `ode_check_trigger@0x6a1dd0`: physics objects with the "can burn" array (`+0xa8c+4i`) that receive a paf whose flags have 0x200000 (`+0x9ac & 0x200000`) catch fire: flame FX object (type 0xd) attached, ignition time stored (`+0xc9c`), intensity `+0xc18 = 0.5`. Each frame intensity += 0.01 until 2.0 (frame based); the flame FX gets the object's velocity*0.25 and size*0.7. When intensity >= 1.5: every object touching it (`fn@0x42fdc0(...,0x80000)`) and every linked object (`fn@0x437370`, 10 max) that is not already in the burning list gets a paf (flags 0x200000, damage 0, direction from burner to target) = fire spreads between wooden props. After 10.0 s since ignition the object's flags are changed (`fn@0x415570/415490(obj,1)`) and the flame FX attribute 0x3332 set to 10 (extinguish/burnt-out visual; [L]).
- `SFX_NET_Fire_*@0x4d6830..` (fire line along a network): `ETAT_Init`: spacing `this+0x180=1.4` (`0x3fb33333`), speed `this+0x17c = length(0x1a8)/this[0x178]` (traverse time), clears 100 flame handles; if the level saved flag says already burnt the extent is set to the full length; `ETAT_Burn`: remaining time `this+0x184` (-1 = forever) decreases by dt and the fire ends at 0; extent `+0x1a0` grows `dt*speed` up to `+0x1a8`; a flame FX (`fn@0x4d5180`: 100 slots, fixed colour/scale constants: size 0.1/1.0, 0.75, life 6.0, ...) is placed every 1.4 along the front; while Jack holds item 6, 7 or 8 (G+0x3348) `fn@0x4d5b60` makes a **fire zone** (sphere r 0.5) at the fire point nearest to the held tip so the spear/torch lights.
- Fire zones: `Fire_PointInFireZone@0x6e3210` loops the zone list (type 0x17): kind 0 sphere (centre, r; strict `<`), kind 1 segment (base, axis, r; projection t must be in (0,1), distance^2 < r^2). Used by `Javelin_waittaken@0x87d160`, `it_loop_off@0x4ce740` (torches), `Xenon_Activate_Light_check@0x6d6730` (lamps), `H_callback_after_blend@0x596090` (Jack).

## Gaps
- Burn time and spread interval of the actual levels are trigger/instance data (not decoded) [G].
- What exactly ignites a start cell from a burning javelin/torch is a level script (`TrigTest_*` + `TrigExec_Burn`); the javelin itself only carries the flag (`KAnn_exec_action_javelin_set_fire@0x5ffb50` sets `Javelin+0x3c=1` at animation frame 65 of anim 0x5f; `Javelin_launch@0x879190` checks material 5 cells along a flying lit spear and stops it in grass). Which trigger pairs these is level data.
- Jack's fire damage is in `H_callback_after_blend@0x596090` (decompile timed out); only the flag `this+0x3cc8` (5x5 proximity, set for AI companions only) and the fire-zone call are known. See `E04.md`.
- Meaning of `X+0x8938` (non-zero gate of every creature check) is [L] "level contains grid fire"; its writer was not found.
- Floating-point detail of `fn@0x41ea90(x,200)` (wrap vs clamp) assumed wrap [L].
- PS2 build may use frame-based timers (ODE flame growth is already per frame).
