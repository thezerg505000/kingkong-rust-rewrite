# KF02 Chest pounding
## Behaviour (what the game does)
Fury starts with Kong's chest-beat/roar animation. Phase 4 plays animation **0xab** (the pound, start at
`fn@0x884f00`) and then **0xad** (the roar, `fn@0x883430(0xad)`); `k_exec_fury` treats the span anim 0xab frame > 25 (0x19, in phase 4) .. anim 0xad frame < 140 (0x8c) specially (a scene-lighting dim, see KF06). While
the pound is held a **shout stimulus** (kind 2, list 0x14) is emitted each frame, its radius growing
10/s up to 30.0; creatures in range react: the rex goes to `cri` (roar) and aborts a charge, the raptor
(`KR_exec_check_fury`) reacts within 35.0, bats (`KBC_exec_check_fury`) within 50.0.
## Code
`k_ETAT_main@0x89a120` case 4; `fn@0x884f00`; `fn@0x883430`; `KT_exec_check_fury@0x4b95d0`
(radius 30.0), `KR_exec_check_fury@0x65ddd0` (35.0), `KBC_exec_check_fury@0x7cfde0` (50.0).
## Numbers
Shout radius +10/s, cap 30.0 [C `_DAT_00a88e24`, `_DAT_00a88e14`]; reaction radii 30/35/50 [C]; anim ids 0xab/0xad [C].
