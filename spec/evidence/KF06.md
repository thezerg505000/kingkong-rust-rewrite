# KF06 Visual transformation
## Behaviour (what the game does)
While fury is on (and fading in/out around it) the post-process object `DAT_00b99fb8` is driven by Kong's AI:
several channels (colour balance, contrast, black-and-white, blur, remanence/persistence, "eclair" contrast
for hits) move toward `configured value x coef`, where `coef` = `timer <= 5 ? timer/5 : 1`, smoothed. A
music/ambience parameter (id 0xca) follows `min(timer/4, 0.8)`.
## Code
`k_exec_fury@0x8b1d00` (registered by `k_tag_on@0x894c10`): constants `_DAT_00a88ecc`=4.0, `_DAT_00a88f08`=0.8,
`_DAT_00a88e20`=5.0, rates 0.2 (off), 1.0 (on), 3.0 (ramp <= 5 s), 10.0 (floor), channel lerp 5.0 x dt; engine
setters `fn@0x6934e0`, `fn@0x693890`, `fn@0x6932f0`, `fn@0x693590` (post-process channels, `DAT_00b99fb8`);
`fn@0x6e5180(.., 0xca, v)` = audio parameter. During the pound/roar span (phase 4 with anim 0xab frame > 25, or anim 0xad frame <= 140) a scalar (`Kong+0x...`,
named `i_finish_init` in the model) falls toward 0 at 0.2/s (`fn@0x88cb40` is called), and is restored at 5.0/s (to 1.0)
afterwards (`fn@0x88cbb0`); while it is below 1.0 it is written into 6 of the 8 entries `DAT_00b99fd4+0x4d48+4k`
(k = 0..7 except 1 and 7) and flag bit 2 of `DAT_00b99fd4+0x4904` is raised: a dimming of six scene light groups
around the roar `[L]`.
## Numbers
coef = min(timer/5, 1) [C]; audio = min(timer/4, 0.8) [C]; blend rates above [C]. The actual colour values
(`f_fury_afx_colorbalance1/2`, `_contraste`, `_blackandwhite`, `_blur`, `_remanance`, `_coef`, `f_volume_fury`,
`f_fury_time_Volnull`) are per-level Kong-instance data, not in the exe.
## Data
