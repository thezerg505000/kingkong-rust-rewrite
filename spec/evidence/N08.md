# N08 Predator awareness (companions reacting to dangerous creatures)
## Behaviour
Companions react to a creature through their stimulus/vision code and then through per-creature-kind numbers from the Univers table: how close the creature may come before the companion stops shooting and backs off ("safe distance"), at what distance it raises alert flags, and which kinds it ignores. Reaction states: assist/shoot (N04), cover (`H_ETAT_IA_hide` 0x25b, `H_ETAT_IA_MultiCover` 0x263), stunned/limp when hurt (`H_ETAT_IA_walkstunned` 0x264, `H_ETAT_IA_stunned`), grabbed by raptor/scolo/scorpion/swamp/crab (`H_ETAT_IA_grab*`, ids 0x2c7, 0x2ca, 0x2cd...).
## Code
- `H_exec_read_world@0x586420` fills the vision list (`this+0xc60` target, `this+0xc7c` kind, `this+0xab0/0xab4` threat flags), `H_exec_serveur_get@0x5b0a70` reads the creature's state, `H_exec_ch_Stimulus_Paf@0x5a3060` the hits. The kinds that count are the `PNJ_Raptor` type ids (16 T-Rex, 14 Venatosaurus, 22 small, ...) [C for 14/16/22].
- Alert radius per kind (`H_ETAT_IA_tir`): `safe^2 + 2` if the kind's flag `G+0x310c+4k == 1.0`, else `engage^2 + 4`; inside it the companion raises `this+0xba0` (alert) and `this+0xc4c` (moving) [C]. Table in N04.md.
- Ignored kinds 0x1d, 0x1e in `H_exec_validate_tir` [C].
## Rust
`companions::{enemy_kind_row, companion_alert_radius_sq}`.
## Gaps
The vision cones and the "danger" flags written by `H_exec_read_world` are not ported; the kinds 13, 20, 23, 27, 28 are unnamed creatures.
