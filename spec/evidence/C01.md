# C01 First-person viewpoint
Main doc `J06.md` (eye height/offset) and `J05.md` (look). The camera object is placed at Jack's body position + (0, -0.02, eye height + bob) every frame (`CM_Cam@0x45b1b0`
0x45dd09-0x45de10, `fn@0x414ae0` set position). Eye height 1.6 standing / 0.8 crouched / 1.45 / 1.4 flag variants, eased with 5*dt [C]. Head bob (camera +0xcc, added to the height): lerp with 4*dt or 16*dt toward
a target; one visible term is `sin(time*10) * 0.03` (0x45b69e-0x45b6bb: `fn@0x43c600` time, `fn@0x414720`..); amplitudes 0.06/0.04/0.08/0.005 and the state selection (+0x23c value 1..3) not mapped [L].
Rust: `eye_target`, `smooth_eye`. Gaps: head bob, +0xcc composition.
