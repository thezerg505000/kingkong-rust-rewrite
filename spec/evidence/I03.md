# I03 Active weapon restriction
## Behaviour (what the game does)
While a non-firearm is in the hand slot, guns cannot be fired or reloaded: the fire/aim mapping and `TrigTest_Arme` class 200 ("a gun is held") are false. Throwing or dropping empties the hand slot and the stored gun comes back.

## Code
`Jack_IsNonFirearmHeld`@0x68b930 (A in 5..10) [C]; `TrigTest_Arme`@0x469980 class 200 = A/B/C in 1..4 (firearm carried), class 100 = any slot in 5..8 (throwable carried) [C]; `H_exec_read_joy` branches on both; `Jack_ConsumeThrownWeapon`@0x68db70: after a throw A := B (or the lever), B := 0 [C].
Weapon 8 stays in hand while its stack is non-empty.

## Rust
`Slots::{can_fire_gun, non_firearm_held, carries_throwable, consume_after_throw}`.
