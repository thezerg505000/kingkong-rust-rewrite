# J04 Analog movement
Speed scales linearly with the deadzoned stick magnitude L (`stick_magnitude`), direction is a continuous angle.
- Deadzone: `fn@0x43cb00@0x43cb00` mode 3: per axis |v| < 0.15 -> 0, else (|v|-0.15)/0.85; clamp [-1,1] first; scale 1.0 [C].
- Second threshold: movement only starts at L >= 0.25 (so effective raw radius about 0.36 on-axis) and `joy_norm` ramps 0..1 over
  L in [0.25, 0.925] [C GG_Exec_Joy@0x695030]. `joy_norm` only gates movement (select_action tests it != 0); the speed itself uses L [C].
- Below 0.25 the horizontal velocity is set to 0 and the smoothed speed is reset (stop is immediate, not eased) [C].
Rust: `normalize_stick`, `stick_magnitude`, `move_direction`; tests `deadzone_rescales_to_full_range`, `move_direction_thresholds`.
