# KC04 Upward repel
Main document: `spec/evidence/KC01.md`.

## Behaviour (what the game does)
After a punch (or from idle) the special button plays anim 0xac (phase 3). The blow carries class **0x14** (0x10|4: no
life damage, "repel") and damage field 10 (20 in fury): enemies are pushed away/up instead of hurt. A V-Rex ignores the life
damage (class 0x10 is excluded by `KT_exec_check_paf`), a Kong-level raptor takes none either (`KR_exec_check_paf`
skips damage when the 0x10 bit is set) but is repelled. The repel is the hinge of the combo: attack afterwards = downward
strike (KC05), special again (not carrying) = chest pound / fury (KF01). If a living target was proposed (`Kong+0xc`)
the special button goes to the phase-10 strike instead of the repel.

## Code
`fn@0x884e70@0x884e70` (phase 3, anim 0xac, params (2.0, 0.5, 0)), `k_ETAT_main` phase 3 handler (0x89b2aa..0x89b810),
`k_exec_melee_hit` (`ANIM_GetCurrentId == 0xac` -> class 0x14, set after the fury choice, so fury does not change it),
receivers `KT_exec_check_paf@0x49e580`, `KR_exec_check_paf@0x65a8b0`.
