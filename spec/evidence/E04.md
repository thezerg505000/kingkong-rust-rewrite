# E04 Fire damage
## Behaviour
A creature that stands on a burning grid cell is killed: raptors every frame, scorpions every 0.5-1.5 s, megapede (Scolo) body parts every 0.3-0.5 s, each time with a fire paf of 1000 damage (flags 0x200200). Raptors and other species then enter a burn/panic state (`PNJ_Raptor_ETAT_BURN`, left after 8.0 s or when the burning flag clears; bats `BC_ETAT_Brule`). Props burn and pass fire. For Jack: the flag `Jack+0x3cc8` is set when a burning cell is within the 5x5 block around him (`fn@0x68a9b0`); the damage itself is applied inside `H_callback_after_blend@0x596090`, whose decompilation timed out, so Jack's burn damage rate is NOT recovered. Burning spears add +10 damage to a hit (see S docs).
## Code
`PNJ_Raptor_reflex@0x835ea0:302`, `PNJ_Scorpion_reflex@0x4f8610:204`, `PNJ_Scolo_Reflex@0x81a710:334`, `BC_reflex@0x72d400:1055`, `PNJ_Raptor_ETAT_BURN@0x872a10`, `BC_ETAT_Brule@0x746590`, `fn@0x68a9b0@0x68a9b0`, `fn@0x68a930@0x68a930` (ground 1, 0xc or burning), `Msg_SendPaf@0x6e3df0`, `fn@0x6e3e70` (scolo variant with hit point).
## Numbers
1000 damage [C]; flags 0x200200 [C]; scorpion Rand(0.5,1.5), scolo Rand(0.3,0.5) [C]; raptor burn state 8.0 s [C]; Jack radius 2 cells [C]. No per-second DPS exists for creatures: they take lethal pafs. Jack's burn DPS [open].
## Data
Creature hp values from the creature models; the paf 1000 exceeds all of them except the Jack-level V-Rex (hp 2000, see X04 docs: V-Rex reflex is excluded by the `+0x20 != 0x10` test, so it ignores grid fire).
## Rust
`environment::{BURN_PAF_DAMAGE, PAF_FLAGS_FIRE_CREATURE, burn_paf_interval, raptor_burn_state_over, jack_near_fire}`. Test `creature_burn_numbers`, `jack_fire_proximity_is_5x5`.
## Gaps
Jack burn damage/stun and the wound mapping (decompile of `H_callback_after_blend` failed; `wounds` doc H01-H12 lists it as open too). Species not listed (spider `PNJ_Spider_ETAT_Sol@0x4efc00:1645`, `PNJ_Scolo_ETAT_Sol@0x80d5d0:1955`) check the same grid byte; their paf code was not read.
