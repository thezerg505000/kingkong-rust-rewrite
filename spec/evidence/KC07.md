# KC07 Throw enemy
Main document: `spec/evidence/KC06.md` (grab protocol), `spec/evidence/KC12.md` (V-Rex throw), `spec/evidence/B02.md`.

## Behaviour (what the game does)
A throw is a move of the grab protocol: the held creature publishes the move kind and Kong plays the matching
animation; at the release frame the creature is handed to its own `*_ETAT_projectile` state and flies with the velocity of
that state; landing deals damage to the thrown creature. Numbers recovered per receiver:
* **V-Rex** (`KT_ETAT_grabbed` / `projectile`): throw messages 0x17/0x21; impact 20.0; bounce 0.6 (KC12).
* **Kong-level raptor** (`KR_ETAT_projectile@0x652e70`): wall impact (collision flag 0x80 while anim 0x2e) and ground impact (flag 0x40) each subtract
  **5.0** from the raptor's life (`fn@0x770af0(KR+0x183c, 5.0)`) unless `KR+0x520 == 1`.
* **Megapede** (`PNJ_Scolo_ETAT_Grabbed_By_Kong@0x826620`): 5.0 (`fn@0x6f9b90(5.0, ..)`) when the grab link message kind 1 ends.
* **Grab objects** (`KIGO_ETAT_projectile@0x6744d0`): speed `KIGO+0x14` (instance data), hits everything on the way with
  class 2 (0x22 if `KIGO+8 != 0`) and damage `KIGO+0x18`.
Direction: the throw direction is Kong's facing / the stick at release `[L]`; exact vector code is in `k_ETAT_grab` cases 0x14/0x17/0x21 (not decoded).

## Code
`k_ETAT_grab@0x8dae10` (cases 0x17, 0x18, 0x21, 0x22, 0x23 -> `fn@0x889e10`; case 0x14 interpolates the held bone), `KR_ETAT_projectile`,
`KIGO_ETAT_projectile`, `KT_ETAT_projectile@0x4a1fa0`, `fn@0x883540` (release of the held object).
