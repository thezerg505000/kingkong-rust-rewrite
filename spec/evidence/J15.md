# J15 Jack's first-person arms: action kit, weapon clips, weapon parts
## Behaviour
Jack's FPS arms (`_PJ_J...` GAO, 101 TRL clips exported as `arms_000..100` in `jack_fps_arms.glb`) are driven by
action ids like every Jade actor: `fn@0x00423e30` sets the action, `fn@0x00423c90` reads it, `fn@0x004240b0` plays an
anim of it. The kit maps an action id to one or more clips; for the guns the id is a base plus the weapon type
(1 Colt/Luger, 2 Tommy, 3 Shotgun, 4 Sniper), so each gun has its own idle, short idle and reload. Weapon sub-objects
(magazine, shell, cartridge, pump, bolt) are separate GEOs modelled in the weapon's own space; the reload clips carry
them on the prop bones B_Jaf_Anex02 / Anex03 next to the weapon bone Anex01.
## Code
- `H_exec_loading_weapon@0x5ccc70`: reload action = 0x72 + weapon type -> 0x73..0x76; reload sounds from the
  object's bank slots 0x37 / 0x41 / 0x4b / 0x55 (`fn@0x00428060` plays a bank-slot sound, not an anim).
- `H_ETAT_IA_lance@0x5ca1e0` lines 440-480: spear throw action 0x5c (0x56 for weapon types 5, 9, 10); the javelin
  leaves when `fn@0x00423db0` returns 1 (or, for 0x56, after frame 15).
- `H_ETAT_IA_paf` (J14): after a hit the idle anim 0x29/0x2a/0x2b must end before select_action runs again.
## Data
- ff0003eb record 248 at 0x5b070 (724 bytes, cb 0x947070, parent `_PJ_J`): u32 keys indexed by action id. Each key
  is an action record (cb 0x946bf0, 113 records from 0x19acaf) listing TRL keys; the TRL chain 0x1a99c9..0x1e905a is in
  arms clip order. Decoded with the loader emulation (`tools/lvl/runall.py`).
- Weapon parts (ff0003eb, GEO = record + 8): `OBJ_LugerDef_Munition` 0x3fe3d8, `OBJ_tommygun_munition` 0x3ee530,
  `OBJ_shotgun_armement` 0x3eb958 (pump), `OBJ_shotgun_munition` 0x404dc4, `OBJ_sniperrifle_armement` 0x3d63a8 (bolt),
  `OBJ_sniperrifle_munition` 0x40137c; spears `OBJ_LanceSmall` 0x364e0c, `OBJ_LanceMed` 0x35aa30 (bone texture
  1f007960). `OBJ_LugerDef_armement` has no visual: no separate Luger toggle GEO exists.

## Gaps
Which aimed clip belongs to which gun is matched by props, not read from code (the aim actions' caller was not
traced). The shotgun has no aimed clip with its props: the short idle 35 is used. The pump / bolt cycling after a
shot and the Luger hold-open are not in the recovered data [G].
